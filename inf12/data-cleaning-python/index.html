Memeriksa Missing Values

Mendeteksi jumlah dan persentase nilai NaN di seluruh kolom

Penjelasan

Missing values (nilai kosong atau NaN) adalah data yang tidak terisi. Pada Pandas, kita bisa dengan cepat mendeteksinya menggunakan fungsi isnull() digabungkan dengan sum() untuk mengetahui berapa banyak data yang hilang di tiap-tiap kolom.

Langkah-langkah di Colab

  1. Hitung jumlah nilai kosong (NaN) untuk setiap kolom secara keseluruhan.

    Kode Python 
    df.isnull().sum()
    Output Hasil 
    PassengerId      0
Survived         0
Pclass           0
Name             0
Sex              0
Age            177
SibSp            0
Parch            0
Ticket           0
Fare             0
Cabin          687
Embarked         2
dtype: int64

    Penjelasan: Pandas memberikan ringkasan seluruh kolom sekaligus. Anda bisa langsung melihat bahwa Age memiliki 177 data kosong, Cabin memiliki 687 data kosong, dan Embarked memiliki 2.

  2. Hitung persentase nilai kosong untuk menentukan strategi penanganannya nanti.

    Hitung Persentase 
    # Mendapatkan persentase nilai kosong:
missing_pct = (df.isnull().sum() / len(df) * 100).round(2)
print(missing_pct)

02

Menangani Missing Values

Imputasi (mengisi) atau menghapus nilai NaN yang terdeteksi

Penjelasan

Untuk Age, kita akan mengisinya dengan median untuk meminimalisasi efek outlier. Untuk Embarked, kita isi dengan modus (karena kategorikal). Sedangkan Cabin akan kita hapus kolomnya seluruhnya menggunakan drop() karena mayoritas (77%) datanya kosong.

Langkah-langkah di Colab

  1. Mengisi Age dengan Median:

    Imputasi Age 
    # Hitung median usia
median_age = df['Age'].median()
print(f"Median Usia: {median_age}")

# Isi (fillna) sel yang kosong dengan nilai median tersebut
df['Age'].fillna(median_age, inplace=True)
    Output Hasil 
    Median Usia: 28.0

    Penjelasan: Pandas menemukan nilai tengah dari umur (28.0) dan argumen inplace=True memastikan semua NaN di kolom Age langsung ditimpa oleh angka 28 tanpa harus membuat variabel baru.

  2. Mengisi Embarked dengan Modus:

    Imputasi Embarked 
    # Ambil modus menggunakan fungsi mode(), index [0] untuk nilai pertamanya
mode_embarked = df['Embarked'].mode()[0]
print(f"Modus Embarked: {mode_embarked}")

# Isi sel yang kosong
df['Embarked'].fillna(mode_embarked, inplace=True)
    Output Hasil 
    Modus Embarked: S

    Penjelasan: Modus pelabuhan yang paling sering muncul adalah 'S' (Southampton). Dua observasi yang hilang pada Embarked sekarang diisi dengan 'S'.

  3. Menghapus kolom Cabin:

    Hapus Kolom 
    # Menghapus seluruh kolom Cabin (axis=1 otomatis dikelola oleh argumen columns)
df.drop(columns=['Cabin'], inplace=True)
print(df.columns)
    Output Hasil 
    Index(['PassengerId', 'Survived', 'Pclass', 'Name', 'Sex', 'Age', 'SibSp',
       'Parch', 'Ticket', 'Fare', 'Embarked'],
      dtype='object')

    Penjelasan: Terlihat bahwa pada daftar nama-nama kolom setelah kode dijalankan, kolom Cabin sudah tidak ada lagi di dalam DataFrame kita.

Memeriksa Data Duplikat

Mengecek apakah ada observasi baris yang identik

Penjelasan

Data duplikat adalah baris yang memiliki nilai identik. Dalam Pandas, cukup gunakan duplicated().sum() untuk menghitung berapa baris yang merupakan duplikasi penuh dari baris sebelumnya.

Langkah-langkah di Colab

  1. Gunakan metode duplicated() digabung dengan sum().

    Hitung Duplikat 
    # Menghitung jumlah duplikat (semua kolom)
jumlah_duplikat = df.duplicated().sum()
print(f"Jumlah duplikat: {jumlah_duplikat}")
    Output Hasil 
    Jumlah duplikat: 0

    Penjelasan: Dataset asli Kaggle ini tidak memiliki duplikat (0), karena setiap observasi memiliki PassengerId yang sifatnya unik.

Menghapus Data Duplikat

Membersihkan observasi yang ganda jika ditemukan

Penjelasan

Meskipun pada Langkah 3 hasilnya 0, jika di kemudian hari Anda mengolah dataset dan menemukan duplikat, kita bisa menghapusnya secara otomatis dengan fungsi bawaan Pandas drop_duplicates().

Langkah-langkah di Colab

  1. Jalankan drop_duplicates().

df.drop_duplicates(inplace=True)

    Jumlah baris tersisa: 891

Memastikan setiap kolom (Series) memiliki dtype Pandas yang sesuai

Tipe data (dtype) di Pandas mencakup int64, float64, dan object (untuk teks/string). Tipe data ini jauh lebih konsisten daripada di Excel. Kita hanya perlu memverifikasi apakah angka dibaca sebagai teks atau bukan.

06

Menyeragamkan Format Data

Menggunakan metode string bawaan Pandas (.str)

Penjelasan

Untuk melakukan operasi pada kolom bertipe teks (object), Pandas menyediakan accessor .str. Anda tidak perlu menggunakan TRIM atau LOWER di sel yang berbeda lalu menyalinnya kembali. Ini dilakukan secara *in-place*.

Langkah-langkah di Colab

  1. Gunakan str.strip() untuk menghapus spasi ekstra, dan str.lower() / str.upper() untuk case konversi.

    Format String 
    # Bersihkan nama
df['Name'] = df['Name'].str.strip()

# Bersihkan spasi dan kecilkan huruf pada Sex (male/female)
df['Sex'] = df['Sex'].str.strip().str.lower()

# Bersihkan dan huruf besarkan pelabuhan (S/C/Q)
df['Embarked'] = df['Embarked'].str.strip().str.upper()

print(df[['Name', 'Sex', 'Embarked']].head(3))
    Output Hasil 
                               Name     Sex Embarked
0       Braund, Mr. Owen Harris    male        S
1  Cumings, Mrs. John Bradley    female        C
2        Heikkinen, Miss. Laina  female        S

    Penjelasan: Kode berhasil memastikan semua nama bersih dari spasi luar, kolom kelamin menggunakan huruf kecil standar, dan pelabuhan dikapitalisasi ('S', 'C', 'Q').

Memanfaatkan Regular Expression (Regex) dengan fungsi Pandas

Untuk kolom Ticket yang memiliki kombinasi huruf, angka, garis miring, dan titik, kita dapat menggunakan str.replace() yang mendukung pola RegEx secara langsung tanpa rumus panjang berlapis-lapis.

Langkah-langkah di Colab

df['Ticket'] = df['Ticket'].str.replace(r'[/. ]', '', regex=True)

08

Menangani Outlier

Mendeteksi nilai ekstrim (IQR) secara statistik

Penjelasan

Mencari kuartil menggunakan quantile() dan mendeteksi Outlier menggunakan formula IQR. Ini persis sama dengan logika matematika Excel, namun penulisannya lebih modular di Python.

Langkah-langkah di Colab

  1. Hitung Q1, Q3, dan batasnya.

    Hitung Batas Outlier IQR 
    # Mencari titik per kuartil
Q1 = df['Fare'].quantile(0.25)
Q3 = df['Fare'].quantile(0.75)
IQR = Q3 - Q1

# Mendefinisikan batas
batas_bawah = Q1 - 1.5 * IQR
batas_atas = Q3 + 1.5 * IQR
print(f"Batas Atas: {batas_atas}")
    Output Hasil 
    Batas Atas: 65.6344

  2. Tandai dan saring data menggunakan np.where.

    Deteksi Outlier 
    # Array condition (seperti IF statement di Excel)
df['Fare_Status'] = np.where(
    (df['Fare'] < batas_bawah) | (df['Fare'] > batas_atas), 
    'OUTLIER', 'Normal'
)

outlier_count = (df['Fare_Status'] == 'OUTLIER').sum()
print(f"Jumlah Outlier di Kolom Fare: {outlier_count}")
    Output Hasil 
    Jumlah Outlier di Kolom Fare: 116

    Penjelasan: Pandas mendeteksi 116 penumpang yang membayar tiket melebihi batas atas wajar ($65.6). Meskipun secara statistik dilabeli Outlier, di studi kasus Titanic data-data mahal ini umumnya sah untuk dijaga karena menunjukkan penumpang VIP.

09

Memvalidasi Rentang Nilai

Menggunakan kondisi mask boolean untuk mencari anomali

Penjelasan

Jika di Excel Anda membutuhkan helper columns dengan operasi boolean, di Pandas Anda dapat langsung menerapkannya pada seluruh subset untuk menghasilkan "masking" data.

Langkah-langkah di Colab

  1. Mencari baris (filtering) dengan nilai aneh dan merangkum jumlahnya:

    Validasi Logika & Rentang 
    # Age harus 0–120 (Tanda ~ berarti 'NOT' / kebalikan)
invalid_age = (~df['Age'].between(0, 120)).sum()

# Pclass hanya 1, 2, 3
invalid_pclass = (~df['Pclass'].isin([1, 2, 3])).sum()

print(f"Age tidak wajar: {invalid_age}")
print(f"Pclass salah: {invalid_pclass}")
    Output Hasil 
    Age tidak wajar: 0
Pclass salah: 0

    Penjelasan: Tidak ditemukan adanya anomali pada kolom umur maupun pada kelas penumpang. Menandakan data kita cukup valid secara konseptual.

Mengubah Data Kategorikal

Label Encoding dan One-Hot Encoding

Penjelasan

Untuk menyiapkan data bagi model Machine Learning, semua string harus jadi numerik. Python/Pandas menyediakan alat khusus yaitu pd.get_dummies() yang secara drastis lebih mudah digunakan daripada formula IF bertingkat di Excel.

Langkah-langkah di Colab

  1. Label Encoding — Sex: Map dictionary (Pria:1, Wanita:0).

    Map Encoding 
    # Melakukan map teks ke nilai angka
df['Sex_Encoded'] = df['Sex'].map({'male': 1, 'female': 0})
print(df[['Sex', 'Sex_Encoded']].head(3))
    Output Hasil 
          Sex  Sex_Encoded
0    male            1
1  female            0
2  female            0

  2. One-Hot Encoding — Embarked: Menggunakan get_dummies().

    Dummies (One-Hot) 
    # Membuat otomatis 3 kolom biner (True/False yang berfungsi sbg 1/0)
df = pd.get_dummies(df, columns=['Embarked'], prefix='Emb')
print(df[['Emb_C', 'Emb_Q', 'Emb_S']].head(3))
    Output Hasil 
       Emb_C  Emb_Q  Emb_S
0  False  False   True
1   True  False  False
2  False  False   True

    Penjelasan: Fungsi Pandas get_dummies() jauh mempermudah pembuatan kolom dummy dibandingkan Excel, yang mengharuskan kita membuat kolom baru satu-persatu dan menuliskan fungsi IF.

Menghapus Kolom Tidak Relevan

Membuang noise yang tidak digunakan untuk model prediksi

Penjelasan

Kolom identifikasi (PassengerId, Ticket) biasanya dihapus agar model ML tidak menghafalnya. Kita bisa menghapus banyak kolom sekaligus dengan menyuplai daftar (List) di Pandas.

Langkah-langkah di Colab

  1. Jalankan drop() dengan argumen daftar kolom.

    Drop Multi-Columns 
    # Hapus kolom ID, tiket, hasil status fare, dan jenis kelamin asli (karena kita sudah punya Sex_Encoded)
df.drop(columns=['PassengerId', 'Ticket', 'Sex', 'Fare_Status'], inplace=True, errors='ignore')
print(df.columns)
    Output Hasil 
    Index(['Survived', 'Pclass', 'Name', 'Age', 'SibSp', 'Parch', 'Fare',
       'Sex_Encoded', 'Emb_C', 'Emb_Q', 'Emb_S'],
      dtype='object')

    Penjelasan: Kolom-kolom yang tidak diperlukan atau redundan (seperti Sex String karena kita memiliki Sex_Encoded, dan PassengerId yang nilainya terisolasi untuk tiap-tiap entitas) berhasil terbuang bersih.

12

Feature Engineering

Berekspresi tingkat tinggi dengan Pandas untuk meramu fitur baru

Penjelasan

Python memungkinkan feature engineering yang rumit di Excel menjadi hal yang satu-baris saja. Kita bisa mendefinisikan kelompok (binning) pada usia atau mengekstrak prefix "Title" secara elegan.

Langkah-langkah di Colab

  1. FamilySize & IsAlone:

    Matematika Kolom 
    # FamilySize = Pasangan/Saudara + Orangtua/Anak + Diri Sendiri
df['FamilySize'] = df['SibSp'] + df['Parch'] + 1

# IsAlone jadi Integer 1 jika ukuran keluarga 1, selain itu 0
df['IsAlone'] = (df['FamilySize'] == 1).astype(int)
print(df[['SibSp', 'Parch', 'FamilySize', 'IsAlone']].head(3))
    Output Hasil 
       SibSp  Parch  FamilySize  IsAlone
0      1      0           2        0
1      1      0           2        0
2      0      0           1        1

  2. Title (Gelar): Mengekstrak Mr/Mrs/Miss dari teks String name.

    Ekstrak Regex Grouping 
    # Cari kata yang didahului koma spasi dan diakhiri titik
df['Title'] = df['Name'].str.extract(r', ([A-Za-z]+)\.', expand=False)
print(df['Title'].value_counts().head(4))
    Output Hasil 
    Title
Mr        517
Miss      182
Mrs       125
Master     40
Name: count, dtype: int64

  3. AgeGroup: Melakukan Binning dengan pd.cut().

    Binning dengan pd.cut 
    # Memotong dataset Age ke keranjang/kelompok umur
df['AgeGroup'] = pd.cut(
    df['Age'], 
    bins=[0, 12, 18, 60, 120], 
    labels=['Anak', 'Remaja', 'Dewasa', 'Lansia']
)
print(df[['Age', 'AgeGroup']].head(3))
    Output Hasil 
        Age AgeGroup
0  22.0   Dewasa
1  38.0   Dewasa
2  26.0   Dewasa

    Penjelasan: Feature Engineering berhasil menciptakan kolom `FamilySize` (penjumlahan otomatis), `IsAlone` (evaluasi ke integer 0/1 otomatis), `Title` menggunakan regex, dan `AgeGroup` dengan pd.cut secara bersih dan tanpa menggunakan Excel Macro / Formula yang berat.
