Syntax Dasar & Hello World

Mengenal struktur dasar file PHP, cara menampilkan teks, dan jenis komentar.

Penjelasan

Kode PHP harus selalu diapit oleh tag <?php dan ?>. Setiap baris instruksi (statement) di PHP harus diakhiri dengan titik koma (;). Untuk menampilkan output ke layar, kita bisa menggunakan perintah echo atau print. Perbedaan utamanya: echo bisa menerima banyak argumen sekaligus, sedangkan print hanya satu dan selalu mengembalikan nilai 1.

echo & print

Menampilkan Teks 
<?php
echo "Hello, World!";
echo "\n";
print "Selamat belajar PHP!";
?>
Output Hasil 
Hello, World!
Selamat belajar PHP!

Jenis Komentar

Komentar digunakan untuk memberikan catatan pada kode. PHP mendukung tiga jenis komentar: // untuk satu baris, # untuk satu baris (alternatif), dan /* ... */ untuk multi-baris.

Tiga Jenis Komentar 
<?php
// Ini komentar satu baris (gaya C++)
# Ini juga komentar satu baris (gaya Shell)

/*
  Ini komentar multi-baris.
  Bisa mencakup beberapa baris sekaligus.
*/

echo "Komentar tidak akan tampil di output.";
?>
Output Hasil 
Komentar tidak akan tampil di output.

PHP di dalam HTML

PHP bisa disisipkan langsung ke dalam file HTML. Server akan memproses bagian yang diapit tag PHP dan meninggalkan HTML lainnya.

Embed PHP ke HTML 
<!DOCTYPE html>
<html>
<body>
  <h1><?php echo "Judul dari PHP"; ?></h1>
  <p>Ini paragraf HTML biasa.</p>
  <p><?php echo "Dan ini dari PHP juga!"; ?></p>
</body>
</html>
Output di Browser 
Judul dari PHP
Ini paragraf HTML biasa.
Dan ini dari PHP juga!
01

Variabel & Tipe Data

Cara menyimpan data, mengenali tipe, dan menggunakan konstanta.

Penjelasan

Variabel di PHP selalu diawali dengan tanda $. PHP bersifat loosely typed, artinya Anda tidak perlu mendeklarasikan tipe datanya secara eksplisit. Tipe data utama di PHP meliputi: String, Integer, Float, Boolean, Array, NULL, dan Object. Anda bisa mengecek tipe data variabel menggunakan gettype() atau var_dump().

Deklarasi Variabel & Tipe Data

Variabel Dasar 
<?php
$nama = "Budi";       // String
$umur = 25;            // Integer
$berat = 65.5;         // Float
$is_aktif = true;      // Boolean
$alamat = null;        // NULL

echo "Nama: $nama\n";
echo "Umur: $umur tahun\n";
echo "Berat: $berat kg\n";
var_dump($is_aktif);
echo "\n";
var_dump($alamat);
?>
Output Hasil 
Nama: Budi
Umur: 25 tahun
Berat: 65.5 kg
bool(true)
NULL

Konstanta (define & const)

Konstanta adalah nilai yang tidak bisa diubah setelah dideklarasikan. Gunakan define() untuk konstanta global atau const di dalam class.

Konstanta 
<?php
define("NAMA_APP", "PHP Tutorial");
define("VERSI", 8.2);

echo NAMA_APP . " versi " . VERSI;
?>
Output Hasil 
PHP Tutorial versi 8.2

Type Casting (Konversi Tipe)

Anda bisa mengubah tipe data variabel secara manual menggunakan type casting dengan sintaks (tipe).

Type Casting 
<?php
$angka_str = "42";
$angka_int = (int)$angka_str;
$angka_float = (float)"3.14";
$ke_string = (string)100;

var_dump($angka_str);   echo "\n";
var_dump($angka_int);   echo "\n";
var_dump($angka_float); echo "\n";
var_dump($ke_string);
?>
Output Hasil 
string(2) "42"
int(42)
float(3.14)
string(3) "100"

Penggabungan String (Concatenation)

Di PHP, kita menggabungkan string menggunakan operator titik (.), atau langsung menyisipkan variabel di dalam string berpetik ganda ("...").

Concatenation 
<?php
$depan = "Budi";
$belakang = "Santoso";

// Cara 1: Operator titik (.)
echo $depan . " " . $belakang . "\n";

// Cara 2: Interpolasi dalam double-quote
echo "Nama lengkap: $depan $belakang\n";

// Cara 3: Operator .= (append)
$pesan = "Halo, ";
$pesan .= $depan;
echo $pesan;
?>
Output Hasil 
Budi Santoso
Nama lengkap: Budi Santoso
Halo, Budi
02

Operator

Aritmatika, perbandingan, logika, dan penugasan.

Penjelasan

PHP memiliki berbagai jenis operator: Aritmatika (+, -, *, /, %, **), Penugasan (=, +=, -=, .=), Perbandingan (==, ===, !=, !==, >, <), dan Logika (&&, ||, !). Penting memahami perbedaan == (membandingkan nilai saja) dan === (membandingkan nilai dan tipe data).

Operator Aritmatika

Aritmatika 
<?php
$a = 15;
$b = 4;

echo "Tambah  : " . ($a + $b) . "\n";
echo "Kurang  : " . ($a - $b) . "\n";
echo "Kali    : " . ($a * $b) . "\n";
echo "Bagi    : " . ($a / $b) . "\n";
echo "Modulus : " . ($a % $b) . "\n";
echo "Pangkat : " . ($a ** 2) . "\n";
?>
Output Hasil 
Tambah  : 19
Kurang  : 11
Kali    : 60
Bagi    : 3.75
Modulus : 3
Pangkat : 225

Perbandingan: == vs ===

Operator == hanya membandingkan nilai. Operator === membandingkan nilai dan tipe data sekaligus (strict comparison).

== vs === 
<?php
$x = 5;      // Integer
$y = "5";    // String

var_dump($x == $y);  echo " // == (nilai saja)\n";
var_dump($x === $y); echo " // === (nilai + tipe)\n";
var_dump($x != $y);  echo " // !=\n";
var_dump($x !== $y); echo " // !==\n";
?>
Output Hasil 
bool(true)  // == (nilai saja)
bool(false) // === (nilai + tipe)
bool(false) // !=
bool(true)  // !==

Operator Logika & Ternary

Logika & Ternary 
<?php
$umur = 20;
$punya_ktp = true;

// Operator Logika: && (AND), || (OR), ! (NOT)
if ($umur >= 17 && $punya_ktp) {
    echo "Boleh memilih dalam Pemilu.\n";
}

// Ternary Operator (singkatan if-else)
$status = ($umur >= 18) ? "Dewasa" : "Anak-anak";
echo "Status: $status\n";

// Null Coalescing Operator (??)
$username = null;
echo "User: " . ($username ?? "Guest");
?>
Output Hasil 
Boleh memilih dalam Pemilu.
Status: Dewasa
User: Guest
03

Struktur Kontrol (Percabangan)

Mengatur alur program menggunakan if-elseif-else dan switch-case.

Penjelasan

Percabangan memungkinkan kita menjalankan blok kode tertentu hanya jika suatu kondisi terpenuhi (bernilai true). Untuk satu/dua kondisi gunakan if-else. Untuk banyak kondisi terhadap satu variabel, gunakan switch-case yang lebih rapi.

Percabangan if-elseif-else

if-elseif-else 
<?php
$nilai = 85;

if ($nilai >= 90) {
    $grade = "A";
} elseif ($nilai >= 80) {
    $grade = "B";
} elseif ($nilai >= 70) {
    $grade = "C";
} elseif ($nilai >= 60) {
    $grade = "D";
} else {
    $grade = "E";
}

echo "Nilai: $nilai → Grade: $grade";
?>
Output Hasil 
Nilai: 85 → Grade: B

Switch-Case

switch cocok untuk memeriksa satu variabel terhadap banyak kemungkinan nilai. Jangan lupa kata kunci break di setiap case!

Switch-Case 
<?php
$hari = "Senin";

switch ($hari) {
    case "Senin":
    case "Selasa":
    case "Rabu":
    case "Kamis":
    case "Jumat":
        echo "$hari: Hari kerja.";
        break;
    case "Sabtu":
    case "Minggu":
        echo "$hari: Hari libur!";
        break;
    default:
        echo "Hari tidak dikenali.";
}
?>
Output Hasil 
Senin: Hari kerja.
04

Perulangan (Looping)

for, while, do-while, dan foreach.

Penjelasan

Perulangan menjalankan blok kode berulang kali. Gunakan for jika jumlah iterasi sudah diketahui, while jika kondisi dicek sebelum iterasi, do-while jika blok harus dijalankan minimal satu kali, dan foreach khusus untuk mengiterasi array.

For Loop

For Loop 
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "Iterasi ke-$i\n";
}
?>
Output Hasil 
Iterasi ke-1
Iterasi ke-2
Iterasi ke-3
Iterasi ke-4
Iterasi ke-5

While Loop

While Loop 
<?php
$hitung = 1;

while ($hitung <= 3) {
    echo "Hitung: $hitung\n";
    $hitung++;
}
?>
Output Hasil 
Hitung: 1
Hitung: 2
Hitung: 3

Foreach (Khusus Array)

foreach adalah cara paling mudah dan aman untuk melakukan iterasi pada setiap elemen array. Tersedia sintaks $value saja atau $key => $value.

Foreach 
<?php
$warna = ["Merah", "Hijau", "Biru"];

foreach ($warna as $index => $w) {
    echo "[$index] $w\n";
}
?>
Output Hasil 
[0] Merah
[1] Hijau
[2] Biru

Break & Continue

break menghentikan loop secara total. continue melewatkan sisa iterasi saat ini dan lanjut ke iterasi berikutnya.

Break & Continue 
<?php
for ($i = 1; $i <= 10; $i++) {
    if ($i == 3) continue; // Lewati angka 3
    if ($i == 7) break;    // Berhenti di angka 7
    echo "$i ";
}
?>
Output Hasil 
1 2 4 5 6
05

Fungsi (Function)

Membungkus logika agar dapat digunakan kembali (Reusable).

Penjelasan

Fungsi adalah blok kode yang diberi nama dan dirancang untuk melakukan tugas tertentu. Keuntungannya: kode lebih rapi, mudah dipelihara, dan bisa dipanggil berkali-kali (reusable). Fungsi bisa memiliki parameter, nilai default, dan mengembalikan nilai dengan return.

Fungsi Dasar & Return

Fungsi Dasar 
<?php
function sapa($nama) {
    return "Halo, " . $nama . "! Selamat datang.";
}

echo sapa("Andi") . "\n";
echo sapa("Siti");
?>
Output Hasil 
Halo, Andi! Selamat datang.
Halo, Siti! Selamat datang.

Default Parameter & Banyak Parameter

Default Parameter 
<?php
function hitungLuas($panjang, $lebar = 10) {
    return $panjang * $lebar;
}

echo "Luas 1: " . hitungLuas(5, 8) . "\n";
echo "Luas 2: " . hitungLuas(5) . " (lebar default=10)";
?>
Output Hasil 
Luas 1: 40
Luas 2: 50 (lebar default=10)

Variable Scope (Lingkup Variabel)

Variabel yang didefinisikan di luar fungsi tidak bisa diakses di dalam fungsi, dan sebaliknya. Gunakan global untuk mengakses variabel global di dalam fungsi.

Variable Scope 
<?php
$pesan = "Halo dari luar!";

function tampilkan() {
    // $pesan tidak bisa diakses langsung
    global $pesan;
    echo $pesan . "\n";

    $lokal = "Saya variabel lokal.";
    echo $lokal . "\n";
}

tampilkan();
// echo $lokal; // Error! Tidak bisa diakses
?>
Output Hasil 
Halo dari luar!
Saya variabel lokal.

Anonymous Function (Closure)

Anonymous function (fungsi tanpa nama) dapat disimpan ke variabel atau digunakan sebagai callback.

Anonymous Function 
<?php
$kali_dua = function($n) {
    return $n * 2;
};

echo $kali_dua(5) . "\n";
echo $kali_dua(12);
?>
Output Hasil 
10
24

Array

Indexed, Associative, Multidimensi, dan fungsi-fungsi Array.

Penjelasan

Array adalah struktur data yang bisa menyimpan banyak nilai dalam satu variabel. PHP mendukung Indexed Array (indeks numerik otomatis), Associative Array (indeks berupa string/key), dan Array Multidimensi (array di dalam array). PHP juga menyediakan banyak fungsi bawaan untuk memanipulasi array.

Indexed Array

Indexed Array 
<?php
$buah = ["Apel", "Pisang", "Jeruk", "Mangga"];

echo $buah[0] . "\n";  // Elemen pertama
echo $buah[2] . "\n";  // Elemen ketiga
echo "Jumlah: " . count($buah) . "\n";

// Menambah elemen baru
$buah[] = "Durian";
echo "Setelah tambah: " . count($buah);
?>
Output Hasil 
Apel
Jeruk
Jumlah: 4
Setelah tambah: 5

Associative Array

Associative Array 
<?php
$mahasiswa = [
    "nama"  => "Dewi Lestari",
    "nim"   => "2024001",
    "jurusan" => "Teknik Informatika",
    "ipk"   => 3.85
];

echo "Nama   : " . $mahasiswa["nama"] . "\n";
echo "NIM    : " . $mahasiswa["nim"] . "\n";
echo "Jurusan: " . $mahasiswa["jurusan"] . "\n";
echo "IPK    : " . $mahasiswa["ipk"];
?>
Output Hasil 
Nama   : Dewi Lestari
NIM    : 2024001
Jurusan: Teknik Informatika
IPK    : 3.85

Array Multidimensi

Array Multidimensi 
<?php
$siswa = [
    ["Andi",  90, "A"],
    ["Budi",  75, "B"],
    ["Citra", 85, "A"]
];

echo "Nama  | Nilai | Grade\n";
echo "------+-------+------\n";
foreach ($siswa as $s) {
    echo str_pad($s[0], 6) . "| " . $s[1] . "    | " . $s[2] . "\n";
}
?>
Output Hasil 
Nama  | Nilai | Grade
------+-------+------
Andi  | 90    | A
Budi  | 75    | B
Citra | 85    | A

Fungsi-fungsi Array Penting

PHP menyediakan banyak fungsi bawaan: count(), sort(), array_push(), array_pop(), in_array(), array_merge(), array_keys(), dll.

Fungsi Array 
<?php
$angka = [5, 2, 8, 1, 9];

// Sort (ascending)
sort($angka);
echo "Sorted  : " . implode(", ", $angka) . "\n";

// array_push & array_pop
array_push($angka, 100);
echo "Push 100: " . implode(", ", $angka) . "\n";

$removed = array_pop($angka);
echo "Pop     : dihapus=$removed → " . implode(", ", $angka) . "\n";

// in_array
echo "Ada 8?  : " . (in_array(8, $angka) ? "Ya" : "Tidak");
?>
Output Hasil 
Sorted  : 1, 2, 5, 8, 9
Push 100: 1, 2, 5, 8, 9, 100
Pop     : dihapus=100 → 1, 2, 5, 8, 9
Ada 8?  : Ya
07

PBO / OOP Dasar

Class, Object, Constructor, Visibility, dan Inheritance.

Penjelasan

OOP (Object-Oriented Programming) mengorganisir kode ke dalam Class (cetak biru) dan Object (instansi). Class memiliki Properties (data) dan Methods (perilaku). Konsep penting OOP: Encapsulation (menyembunyikan detail internal), Inheritance (pewarisan), dan Polymorphism (banyak bentuk). Visibility mengatur akses: public (bisa diakses dari mana saja), private (hanya di dalam class itu), dan protected (class itu + turunannya).

1. Class, Object & Constructor

Class adalah blueprint, Object adalah instansinya. Property adalah variabel di dalam class, Method adalah fungsinya. Constructor (__construct) adalah method khusus yang otomatis dijalankan saat object dibuat.

Class & Object 
<?php
class Mobil {
    // Properties
    public $merk;
    public $warna;

    // Constructor
    public function __construct($merk, $warna) {
        $this->merk = $merk;
        $this->warna = $warna;
    }

    // Method
    public function info() {
        return "Mobil $this->merk berwarna $this->warna.";
    }
}

// Membuat Object
$mobil1 = new Mobil("Toyota", "Putih");
$mobil2 = new Mobil("Honda", "Hitam");

echo $mobil1->info() . "\n";
echo $mobil2->info();
?>
Output Hasil 
Mobil Toyota berwarna Putih.
Mobil Honda berwarna Hitam.

2. Access Modifier & Encapsulation

Access Modifier: public (bebas diakses), private (hanya di dalam class), protected (di class + class turunan).
Encapsulation: Menyembunyikan data internal (private) dan menyediakan metode getter/setter untuk mengakses/mengubah data secara aman.

Encapsulation 
<?php
class BankAccount {
    private $saldo;

    public function __construct($saldo_awal) {
        $this->saldo = $saldo_awal;
    }

    // Setter (dengan validasi)
    public function setor($jumlah) {
        if ($jumlah > 0) {
            $this->saldo += $jumlah;
            echo "Berhasil setor: Rp" . number_format($jumlah) . "\n";
        }
    }

    // Getter
    public function getSaldo() {
        return $this->saldo;
    }
}

$akun = new BankAccount(10000);
$akun->setor(50000);
// echo $akun->saldo; // ERROR: Tidak bisa akses properti private langsung
echo "Total Saldo: Rp" . number_format($akun->getSaldo());
?>
Output Hasil 
Berhasil setor: Rp50,000
Total Saldo: Rp60,000

3. Inheritance, Polymorphism & Overriding

Inheritance: Mewarisi method/property ke class anak menggunakan extends.
Polymorphism & Overriding: Class anak bisa menulis ulang (menimpa) method dari class induk dengan nama yang sama, sehingga satu fungsi bisa merespon secara berbeda (banyak bentuk) tergantung objek pemanggilnya.

Inheritance & Overriding 
<?php
class Hewan {
    protected $nama;
    public function __construct($nama) {
        $this->nama = $nama;
    }
    public function suara() {
        return "Hewan bersuara...";
    }
}

class Kucing extends Hewan {
    // Overriding method suara()
    public function suara() {
        return $this->nama . " berkata: Meow!";
    }
}

class Anjing extends Hewan {
    // Overriding method suara()
    public function suara() {
        return $this->nama . " berkata: Guk guk!";
    }
}

$hewan1 = new Kucing("Kitty");
$hewan2 = new Anjing("Buddy");

// Polymorphism: method sama, hasil berbeda
echo $hewan1->suara() . "\n";
echo $hewan2->suara();
?>
Output Hasil 
Kitty berkata: Meow!
Buddy berkata: Guk guk!

4. Abstract Class & Interface

Abstract Class: Class yang tidak bisa diinstansiasi, berisi deklarasi method yang wajib diimplementasikan oleh class anaknya.
Interface: Kontrak murni, berisi method kosong (tanpa body) yang mewajibkan class yang melakukan implements untuk membuat fungsi tersebut.

Abstract & Interface 
<?php
// Interface
interface Logger {
    public function log($pesan);
}

// Abstract Class
abstract class Bentuk {
    abstract public function hitungLuas();
}

// Class turunan menerapkan abstract dan interface
class Persegi extends Bentuk implements Logger {
    private $sisi;

    public function __construct($s) {
        $this->sisi = $s;
    }

    // Implementasi abstract method
    public function hitungLuas() {
        return $this->sisi * $this->sisi;
    }

    // Implementasi interface method
    public function log($pesan) {
        echo "[LOG] " . $pesan . "\n";
    }
}

$p = new Persegi(5);
$luas = $p->hitungLuas();
$p->log("Luas persegi adalah: $luas");
?>
Output Hasil 
[LOG] Luas persegi adalah: 25

5. Exception Handling

Untuk menangani error atau kondisi tak terduga, gunakan block try...catch...finally. Gunakan throw new Exception() untuk melempar error secara manual saat validasi gagal.

Try Catch 
<?php
function bagi($a, $b) {
    if ($b == 0) {
        throw new Exception("Error: Tidak bisa dibagi dengan nol!");
    }
    return $a / $b;
}

try {
    echo "Hasil 10 / 2: " . bagi(10, 2) . "\n";
    echo "Hasil 5 / 0: " . bagi(5, 0) . "\n";
    echo "Baris ini tidak akan dijalankan.";
} catch (Exception $e) {
    echo "Exception Ditangkap: " . $e->getMessage() . "\n";
} finally {
    echo "Blok finally selalu dijalankan di akhir.";
}
?>
Output Hasil 
Hasil 10 / 2: 5
Exception Ditangkap: Error: Tidak bisa dibagi dengan nol!
Blok finally selalu dijalankan di akhir.
