Persiapan: Membuka File CSV di Excel

Memastikan data CSV terpisah dengan benar ke dalam kolom

Mengapa Ini Penting?

File CSV ( Comma-Separated Values ) menyimpan data dengan pemisah koma ( , ). Saat dibuka langsung di Excel, ada kemungkinan semua data masuk ke satu kolom saja — terutama jika pengaturan regional komputer Anda menggunakan titik koma ( ; ) sebagai pemisah default (seperti di Indonesia/Eropa). Oleh karena itu, kita perlu memastikan data terpisah dengan benar menggunakan fitur Text to Columns atau Import Data .

Cara 1: Import melalui Menu Data (Direkomendasikan)

  1. Buka Excel → buat workbook baru (kosong).

  2. Klik tab Data → pilih From Text/CSV (atau Get Data → From File → From Text/CSV di versi baru).

  3. Pilih file Titanic-Dataset.csv dan klik Import .

  4. Pada dialog preview yang muncul, pastikan pengaturan berikut:

    Pengaturan Import 
    Pengaturan yang perlu diperhatikan:

Delimiter      : Comma  (pemisah koma)
File Origin   : UTF-8  (atau 65001: Unicode UTF-8)
Data Type     : Based on entire dataset

→ Preview di bawah harus menunjukkan data terpisah
  ke dalam 12 kolom yang berbeda.

  5. Klik Load (atau Transform Data jika ingin melihat di Power Query terlebih dahulu). Data akan termuat ke sheet baru dengan semua kolom terpisah rapi.

Cara 2: Text to Columns (Jika Sudah Terlanjur Buka)

Jika file CSV sudah dibuka dan semua data masuk ke kolom A saja , gunakan Text to Columns:

  1. Seleksi seluruh kolom A (klik header kolom A ).

  2. Klik tab Data → pilih Text to Columns .

  3. Pilih Delimited → klik Next .

  4. Centang Comma sebagai delimiter (hapus centang lainnya). Preview di bawah akan menunjukkan data terpisah ke kolom-kolom.

  5. Klik Next → atur format kolom jika perlu (General untuk semua) → klik Finish .

Perhatian: Kolom Name pada dataset Titanic mengandung koma di dalam tanda kutip (misalnya "Braund, Mr. Owen Harris" ). Metode import via menu Data biasanya menangani ini secara otomatis. Jika menggunakan Text to Columns, pastikan Text qualifier diatur ke tanda kutip ( " ) agar koma di dalam nama tidak ikut dipisah.

Hasil yang Benar

Setelah import berhasil, data harus terlihat seperti ini — setiap kolom terisi dengan benar :

Kolom A Kolom B Kolom C Kolom D Kolom E Kolom F ...
PassengerId Survived Pclass Name Sex Age ...
1 0 3 Braund, Mr. Owen Harris male 22 ...
2 1 1 Cumings, Mrs. John Bradley female 38 ...

Tips: Jika Anda menyimpan file CSV sebagai .xlsx (Excel format) setelah import, Anda tidak perlu mengulangi proses Text to Columns saat membukanya kembali nanti.

01

Memeriksa Missing Values

Identifikasi sel-sel kosong pada setiap kolom dataset

Penjelasan

Missing values (nilai kosong) adalah data yang tidak terisi pada suatu baris. Dalam dataset Titanic, kolom Age , Cabin , dan Embarked memiliki banyak missing values. Langkah pertama data cleaning adalah mengetahui seberapa banyak data yang hilang di setiap kolom agar kita bisa memutuskan penanganan yang tepat.

Langkah-langkah di Excel

  1. Buka file Titanic-Dataset.csv di Excel. Data akan otomatis terisi pada kolom A–L.

  2. Di sheet baru atau area kosong, buat header "Kolom" dan "Jumlah Kosong" .

  3. Gunakan formula COUNTBLANK untuk menghitung jumlah sel kosong di setiap kolom.

    Formula Excel 
    =COUNTBLANK(F2:F892)    → Hitung kosong di kolom Age
=COUNTBLANK(K2:K892)    → Hitung kosong di kolom Cabin
=COUNTBLANK(L2:L892)    → Hitung kosong di kolom Embarked

  4. Gunakan Conditional Formatting untuk menyorot sel kosong: pilih seluruh data → Home → Conditional Formatting → Highlight Cells Rules → Blanks.

02

Menangani Missing Values

Mengisi atau menghapus data kosong dengan strategi yang tepat

Penjelasan

Setelah mengetahui lokasi missing values, kita perlu menanganinya. Strateginya berbeda tergantung jumlah dan tipe data:
• Age (19.87% kosong): Isi dengan nilai median karena data numerik dan bisa memiliki outlier.
• Embarked (0.22% kosong): Isi dengan modus (nilai paling sering muncul) karena data kategorikal.
• Cabin (77.10% kosong): Hapus kolom karena terlalu banyak data hilang.

Langkah-langkah di Excel

  1. Mengisi Age dengan Median: Hitung median terlebih dahulu, lalu isi sel kosong.

    Hitung Median Age 
    — Hitung median Age di sel terpisah:
=MEDIAN(F2:F892)    → Hasilnya ≈ 28

— Lalu gunakan Find & Replace untuk mengisi:
1. Seleksi kolom Age (F2:F892)
2. Ctrl+H → Find: (kosongkan) → Replace: 28
3. Options → Match entire cell contents ✅
4. Replace All

  2. Mengisi Embarked dengan Modus: Cari nilai yang paling sering muncul, lalu isi sel kosong.

    Hitung Modus Embarked 
    — Cari modus Embarked (Ctrl+Shift+Enter untuk array formula):
=INDEX(L2:L892,MATCH(MAX(COUNTIF(L2:L892,L2:L892)),COUNTIF(L2:L892,L2:L892),0))
→ Hasilnya: "S" (Southampton)

— Lalu isi 2 sel kosong Embarked dengan "S"

  3. Menghapus kolom Cabin: Klik kanan header kolom K → Delete. Kolom ini memiliki 77% data kosong sehingga tidak berguna untuk analisis.

Tips: Alternatif lain untuk mengisi Age adalah dengan rata-rata (AVERAGE) , namun median lebih disarankan karena tidak terpengaruh oleh outlier (misalnya penumpang berusia sangat tua).

03

Memeriksa Data Duplikat

Mengecek apakah ada baris data yang sama persis

Penjelasan

Data duplikat adalah baris yang memiliki nilai identik di semua kolom. Duplikat dapat mengakibatkan hasil analisis menjadi bias karena data dihitung lebih dari sekali. Pada dataset Titanic, setiap penumpang seharusnya unik berdasarkan PassengerId .

Langkah-langkah di Excel

  1. Gunakan Conditional Formatting untuk menandai duplikat: Seleksi kolom A (PassengerId) → Home → Conditional Formatting → Highlight Cells Rules → Duplicate Values.

  2. Untuk pemeriksaan menyeluruh, buat kolom helper yang menggabungkan semua kolom:

    Formula Cek Duplikat 
    — Buat kolom helper (misal di kolom M):
=A2&"|"&B2&"|"&C2&"|"&D2&"|"&E2&"|"&F2

— Lalu hitung kemunculan setiap kombinasi:
=COUNTIF(M:M,M2)    → Jika > 1, berarti duplikat

  3. Filter kolom hasil COUNTIF untuk menampilkan hanya baris dengan nilai > 1 .

Pada dataset Titanic, umumnya tidak ditemukan data duplikat karena setiap baris memiliki PassengerId unik. Namun pemeriksaan ini tetap penting sebagai best practice.

04

Menghapus Data Duplikat

Menghilangkan baris data yang sama jika ditemukan

Penjelasan

Jika pada langkah sebelumnya ditemukan data duplikat, langkah ini bertujuan menghapusnya. Excel memiliki fitur bawaan Remove Duplicates yang memudahkan proses ini. Pada dataset Titanic, umumnya tidak ada duplikat, tetapi tetap penting mengetahui caranya.

Langkah-langkah di Excel

  1. Seleksi seluruh data (Ctrl+A atau klik salah satu sel dalam data).

  2. Klik tab Data → klik Remove Duplicates .

  3. Pada dialog yang muncul, centang semua kolom yang ingin dibandingkan (atau pilih Select All), lalu klik OK .

  4. Excel akan menampilkan dialog: "X duplicate values found and removed; Y unique values remain."

Perhatian: Selalu simpan backup data sebelum menghapus duplikat. Fitur Remove Duplicates akan menghapus baris secara permanen dan tidak dapat di-undo setelah file disimpan.

05

Memeriksa Tipe Data

Memastikan setiap kolom memiliki tipe data yang sesuai

Penjelasan

Tipe data yang salah bisa menyebabkan error dalam perhitungan. Misalnya, jika kolom Age terdeteksi sebagai teks, maka operasi matematika akan gagal. Kita perlu memastikan:
• Age dan Fare → Numerik (Number)
• Survived dan Pclass → Numerik/Kategori (Integer)
• Name , Sex , Embarked → Teks (Text)

Langkah-langkah di Excel

  1. Gunakan fungsi TYPE atau ISNUMBER untuk memeriksa tipe data setiap sel:

    Formula Cek Tipe Data 
    =ISNUMBER(F2)     → TRUE jika Age adalah angka
=ISTEXT(E2)       → TRUE jika Sex adalah teks
=TYPE(F2)         → 1=Number, 2=Text, 4=Boolean, 16=Error

  2. Hitung berapa banyak sel yang bukan angka pada kolom numerik:

    Hitung Tipe Salah 
    — Hitung sel teks di kolom Age (seharusnya 0):
=SUMPRODUCT((ISTEXT(F2:F892))*1)

  3. Jika ditemukan tipe data yang salah, konversi menggunakan VALUE() untuk teks→angka atau TEXT() untuk angka→teks.

Tipe Data yang Diharapkan

Kolom Tipe Data Contoh Nilai Catatan

Survived Integer (0/1) 0, 1 Biner: 0=Tidak, 1=Ya
Pclass Integer (1/2/3) 1, 2, 3 Kelas tiket
Name Text Braund, Mr. Owen Nama lengkap
Sex Text male, female Kategorikal

06

Menyeragamkan Format Data

Menghilangkan spasi berlebih dan menyeragamkan penulisan

Penjelasan

Data dari berbagai sumber sering memiliki format yang tidak konsisten: spasi berlebih di awal/akhir teks, huruf besar/kecil yang tidak seragam, atau karakter tidak terlihat. Pada dataset Titanic, ini terutama relevan untuk kolom Name , Sex , dan Embarked .

Langkah-langkah di Excel

  1. Gunakan fungsi TRIM untuk menghapus spasi berlebih dan CLEAN untuk karakter non-cetak:

    Formula Bersihkan Spasi 
    =TRIM(CLEAN(D2))    → Bersihkan kolom Name
=TRIM(E2)            → Bersihkan kolom Sex
=TRIM(L2)            → Bersihkan kolom Embarked

  2. Untuk menyeragamkan huruf kecil pada kolom Sex:

    Formula Seragamkan Huruf 
    =LOWER(TRIM(E2))    → "male", "female" (huruf kecil semua)
=UPPER(TRIM(L2))    → "S", "C", "Q" (huruf besar semua)
=PROPER(TRIM(D2))   → Kapitalisasi awal kata pada Name

  3. Copy hasil formula → Paste Values (Ctrl+Shift+V) untuk mengganti data asli dengan data yang sudah dibersihkan.

07

Membersihkan Karakter Khusus

Menghapus simbol atau karakter yang tidak diperlukan

Penjelasan

Beberapa kolom mengandung karakter khusus yang perlu dibersihkan jika akan dianalisis lebih lanjut. Pada dataset Titanic, kolom Ticket memiliki campuran huruf, angka, dan simbol (misalnya "A/5 21171", "STON/O2. 3101282"). Jika kita ingin menganalisis nomor tiket, karakter ini perlu dibersihkan.

Langkah-langkah di Excel

  1. Gunakan SUBSTITUTE untuk menghapus karakter tertentu dari kolom Ticket:

    Formula Bersihkan Karakter 
    — Hapus /, titik, dan spasi dari Ticket:
=SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(I2,"/",""),".","")," ","")

→ "A/5 21171"  menjadi  "A521171"
→ "STON/O2. 3101282"  menjadi  "STONO23101282"

  2. Untuk mengambil hanya angka dari Ticket, gunakan formula yang lebih kompleks:

    Ekstrak Angka Saja 
    — Array formula (Ctrl+Shift+Enter):
=TEXTJOIN("",TRUE,IF(ISNUMBER(
  MID(I2,ROW(INDIRECT("1:"&LEN(I2))),1)*1),
  MID(I2,ROW(INDIRECT("1:"&LEN(I2))),1),""))

→ "A/5 21171"  menjadi  "521171"

  3. Gunakan Find & Replace (Ctrl+H) sebagai cara cepat menghapus karakter tertentu dari seluruh kolom.

08

Menangani Outlier

Mendeteksi dan menangani nilai yang sangat jauh dari rata-rata

Penjelasan

Outlier adalah nilai yang jauh berbeda dari mayoritas data. Pada dataset Titanic, kolom Fare memiliki outlier yang sangat mencolok — beberapa penumpang membayar harga tiket yang sangat tinggi (misalnya 512.33) dibanding rata-rata. Metode IQR (Interquartile Range) digunakan untuk mendeteksi outlier secara statistik.

Langkah-langkah di Excel

  1. Hitung Q1 , Q3 , dan IQR untuk kolom Fare:

    Formula Hitung IQR 
    — Hitung Quartile dan IQR:
=QUARTILE(J2:J892,1)              → Q1 ≈ 7.91
=QUARTILE(J2:J892,3)              → Q3 ≈ 31.00
=QUARTILE(J2:J892,3)-QUARTILE(J2:J892,1)  → IQR ≈ 23.09

— Batas bawah dan atas:
Batas Bawah = Q1 - 1.5 × IQR ≈ -26.72 (atau 0)
Batas Atas  = Q3 + 1.5 × IQR ≈ 65.63

  2. Tandai outlier dengan formula IF:

    Deteksi Outlier 
    — Tandai outlier di kolom baru (misal "Fare_Status"):
=IF(OR(J2<$P$1-1.5*$P$3, J2>$P$2+1.5*$P$3),"OUTLIER","Normal")

→ Fare = 512.33 → "OUTLIER"
→ Fare = 7.25   → "Normal"

  3. Buat Boxplot untuk visualisasi: Insert → Chart → Box and Whisker. Pilih kolom Fare sebagai data source.

  4. Penanganan: Outlier bisa di- cap (batas atas/bawah), dihapus , atau dibiarkan tergantung konteks analisis.

Tips: Pada kasus Titanic, outlier Fare mungkin memang valid (penumpang kelas 1 membayar sangat mahal). Pertimbangkan konteks sebelum menghapus outlier.

09

Memvalidasi Rentang Nilai

Memastikan setiap nilai berada dalam rentang yang valid

Penjelasan

Validasi rentang nilai memastikan data masuk akal secara logis. Misalnya:
• Age tidak boleh negatif dan tidak mungkin lebih dari ~120
• Pclass hanya boleh berisi 1, 2, atau 3
• Survived hanya boleh berisi 0 atau 1
• Fare tidak boleh negatif

Langkah-langkah di Excel

  1. Buat kolom validasi untuk setiap kolom yang perlu dicek:

    Formula Validasi Rentang 
    — Validasi Age (0–120 tahun):
=IF(AND(F2>=0, F2<=120), "Valid", "INVALID")

— Validasi Pclass (hanya 1, 2, atau 3):
=IF(OR(C2=1, C2=2, C2=3), "Valid", "INVALID")

— Validasi Survived (hanya 0 atau 1):
=IF(OR(B2=0, B2=1), "Valid", "INVALID")

— Validasi Fare (tidak negatif):
=IF(J2>=0, "Valid", "INVALID")

  2. Hitung total data yang invalid per kolom:

    Hitung Data Invalid 
    =COUNTIF(M2:M892,"INVALID")    → Jumlah data yang invalid

  3. Gunakan Data Validation untuk mencegah input nilai di luar rentang: Data → Data Validation → Allow: Whole number/Decimal → Set min & max.

10

Mengubah Data Kategorikal

Mengkonversi data teks menjadi numerik untuk analisis

Penjelasan

Banyak algoritma analisis dan machine learning memerlukan input numerik. Data kategorikal seperti Sex ("male"/"female") dan Embarked ("S"/"C"/"Q") perlu diubah menjadi angka. Ada dua teknik utama:
• Label Encoding : Mengubah kategori menjadi angka (misal: male=1, female=0)
• One-Hot Encoding : Membuat kolom biner baru untuk setiap kategori

Langkah-langkah di Excel

  1. Label Encoding — Sex: Ubah "male"/"female" menjadi angka:

    Label Encoding Sex 
    — Buat kolom "Sex_Encoded":
=IF(E2="male",1,0)

→ "male"   → 1
→ "female" → 0

  2. One-Hot Encoding — Embarked: Buat 3 kolom biner baru:

    One-Hot Encoding Embarked 
    — Buat kolom "Embarked_S":
=IF(L2="S",1,0)

— Buat kolom "Embarked_C":
=IF(L2="C",1,0)

— Buat kolom "Embarked_Q":
=IF(L2="Q",1,0)

Contoh Hasil Encoding

Sex Sex_Encoded Embarked Emb_S Emb_C Emb_Q
male 1 S 1 0 0
female 0 C 0 1 0
female 0 S 1 0 0

Menghapus Kolom Tidak Relevan

Menghilangkan kolom yang tidak berkontribusi pada analisis

Penjelasan

Tidak semua kolom berguna untuk analisis atau prediksi. Kolom-kolom yang hanya berfungsi sebagai identitas unik atau memiliki terlalu banyak variasi tidak memberikan pola yang berguna. Kolom yang biasa dihapus pada dataset Titanic:
• PassengerId : Hanya ID unik, tidak memiliki makna prediktif
• Ticket : Terlalu banyak variasi unik, sulit dikategorikan
• Name : Teks unik (kecuali jika diekstrak title-nya, lihat Step 12)
• Cabin : Sudah dihapus di Step 2 karena terlalu banyak missing values

Langkah-langkah di Excel

  1. Identifikasi kolom yang akan dihapus: PassengerId (kolom A), Name (kolom D), Ticket (kolom I).

  2. Klik header kolom yang ingin dihapus (misal klik huruf "A" di atas). Untuk memilih beberapa kolom, tahan Ctrl dan klik header kolom lainnya.

  3. Klik kanan → Delete . Kolom akan dihapus dan kolom lainnya bergeser ke kiri.

  4. Verifikasi bahwa kolom yang tersisa sesuai kebutuhan analisis.

Feature Engineering

Membuat fitur baru dari data yang ada untuk meningkatkan analisis

Penjelasan

Feature engineering adalah proses membuat kolom/fitur baru dari data yang sudah ada untuk meningkatkan kualitas analisis atau akurasi model prediksi. Pada dataset Titanic, kita bisa membuat beberapa fitur baru yang sangat berguna:
• FamilySize : Jumlah anggota keluarga = SibSp + Parch + 1
• IsAlone : Apakah penumpang sendirian (FamilySize = 1)
• Title : Gelar dari kolom Name (Mr, Mrs, Miss, Master, dll.)
• AgeGroup : Kelompok usia (Anak, Dewasa, Lansia)

Langkah-langkah di Excel

  1. FamilySize: Buat kolom baru yang menjumlahkan SibSp, Parch, dan penumpang itu sendiri:

    Formula FamilySize 
    — Kolom "FamilySize":
=G2+H2+1    → SibSp + Parch + 1 (diri sendiri)

→ SibSp=1, Parch=0 → FamilySize = 2
→ SibSp=0, Parch=0 → FamilySize = 1 (sendirian)

  2. IsAlone: Tandai apakah penumpang bepergian sendirian:

    Formula IsAlone 
    — Kolom "IsAlone":
=IF(G2+H2=0,1,0)

→ 1 = Sendirian, 0 = Bersama keluarga

  3. Title (Gelar): Ekstrak gelar dari kolom Name. Nama dalam format "Braund, Mr. Owen Harris":

    Formula Ekstrak Title 
    — Kolom "Title" — Ekstrak teks antara ", " dan ".":
=MID(D2,FIND(",",D2)+2,FIND(".",D2)-FIND(",",D2)-2)

→ "Braund, Mr. Owen Harris"      → "Mr"
→ "Cumings, Mrs. John Bradley"   → "Mrs"
→ "Heikkinen, Miss. Laina"       → "Miss"
→ "Palsson, Master. Gosta"       → "Master"

  4. AgeGroup: Kelompokkan usia menjadi kategori:

    Formula AgeGroup 
    — Kolom "AgeGroup":
=IF(F2<=12,"Anak",IF(F2<=18,"Remaja",IF(F2<=60,"Dewasa","Lansia")))

→ Age = 2   → "Anak"
→ Age = 15  → "Remaja"
→ Age = 38  → "Dewasa"
→ Age = 70  → "Lansia"
