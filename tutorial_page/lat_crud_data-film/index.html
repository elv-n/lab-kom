Tutorial: Membuat Aplikasi CRUD Film

PHP & MySQL | Langkah demi Langkah

Pendahuluan

Dalam tutorial ini, kita akan membuat aplikasi web sederhana untuk mengelola data film menggunakan PHP dan MySQL. Aplikasi ini memiliki fitur CRUD (Create, Read, Update, Delete).

Apa yang akan kita buat?

  1. Tambah Film — Menambahkan data film baru ke database
  2. Lihat Data — Menampilkan semua data film dalam tabel
  3. Edit Film — Mengubah data film yang sudah ada
  4. Hapus Film — Menghapus data film dari database

Prasyarat

  1. Sudah menginstall Laragon (atau XAMPP)
  2. Laragon sudah berjalan (Apache & MySQL aktif)
  3. Memiliki text editor (Notepad++, VS Code, dll)

Struktur File

app-film/
    ├── koneksi.php
    ├── index.php
    ├── lihat-data.php
    ├── edit-data.php
    └── hapus-data.php

Membuat Folder Project

Langkah pertama, kita perlu membuat folder untuk menyimpan semua file project.

  1. Buka File Explorer
  2. Pergi ke folder Laragon: C:\laragon\www\
  3. Buat folder baru dengan nama: app-film
Info: Folder www adalah document root dari Laragon. Semua project web harus disimpan di sini agar bisa diakses melalui browser.

Setelah folder dibuat, aplikasi bisa diakses di browser dengan alamat: http://localhost/app-film/

2

Membuat Database & Tabel

Sebelum menulis code PHP, kita perlu menyiapkan database MySQL terlebih dahulu.

2.1 Buka phpMyAdmin

  1. Pastikan Laragon sudah berjalan
  2. Buka browser, ketik: http://localhost/phpmyadmin
  3. Login (default: username root, password kosong)

2.2 Buat Database Baru

  1. Klik tab "Database" di bagian atas
  2. Pada kolom "Create database", ketik: db.film
  3. Klik tombol "Create"

2.3 Buat Tabel

  1. Setelah database db.film terbuat, klik database tersebut
  2. Klik tab "SQL"
  3. Ketik query SQL berikut, lalu klik "Go":
CREATE TABLE data_film (
    id INT(11) AUTO_INCREMENT PRIMARY KEY,
    judul VARCHAR(255) NOT NULL,
    tahun INT(4) NOT NULL
);
Penjelasan:
• id — nomor unik otomatis untuk setiap film (AUTO_INCREMENT)
• judul — menyimpan judul film (teks, max 255 karakter)
• tahun — menyimpan tahun rilis film (angka, 4 digit)

Membuat File Koneksi Database

koneksi.php

File ini bertugas menghubungkan PHP dengan database MySQL. File ini akan dipanggil oleh semua halaman lain.

Buat file baru: koneksi.php

Buka text editor, buat file baru, simpan dengan nama koneksi.php di folder app-film. Kemudian ketik code berikut:

<?php
$koneksi = mysqli_connect("localhost", "root", "", "db.film");

if (!$koneksi) {
    die("Koneksi gagal: " . mysqli_connect_error());
}
Penjelasan:
• mysqli_connect() — fungsi PHP untuk terhubung ke MySQL
• Parameter: "localhost" (server), "root" (username), "" (password kosong), "db.film" (nama database)
• die() — menghentikan program jika koneksi gagal

Membuat Halaman Tambah Film

index.php

Halaman ini adalah halaman utama aplikasi. Berisi form untuk menambahkan data film baru ke database.

Buat file baru: index.php

Ketik seluruh code berikut ke dalam file index.php:

<!DOCTYPE html>
<html lang="id">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Tambah Film - App Film</title>
</head>

<body>

    <!-- Header -->
    <header>
        <h1>App Film</h1>
        <p>Aplikasi Manajemen Data Film</p>
    </header>

    <!-- Navbar -->
    <nav>
        <a href="index.php"><b>Tambah Film</b></a> |
        <a href="lihat-data.php">Lihat Data</a>
    </nav>

    <hr>

    <!-- Konten Utama -->
    <main>
        <h2>Tambah Data Film</h2>

        <?php
        if (isset($_POST['submit'])) {
            $judul = $_POST['judul'];
            $tahun = $_POST['tahun'];

            // Koneksi ke database
            include 'koneksi.php';

            // Query untuk menambahkan data film
            $query = "INSERT INTO data_film (judul, tahun)
                     VALUES ('$judul', '$tahun')";
            if (mysqli_query($koneksi, $query)) {
                echo "<p>Data film <b>"
                   . htmlspecialchars($judul)
                   . "</b> berhasil ditambahkan!</p>";
            } else {
                echo "<p>Error: "
                   . mysqli_error($koneksi)
                   . "</p>";
            }

            // Menutup koneksi
            mysqli_close($koneksi);
        }
        ?>

        <form action="" method="post">
            <p>
                <label for="judul">Judul Film:</label><br>
                <input type="text"
                       id="judul"
                       name="judul"
                       placeholder="Masukkan judul film"
                       required>
            </p>

            <p>
                <label for="tahun">Tahun Rilis:</label><br>
                <input type="number"
                       id="tahun"
                       name="tahun"
                       placeholder="Contoh: 2024"
                       required>
            </p>

            <p>
                <input type="submit"
                       name="submit"
                       value="Tambah Film">
            </p>
        </form>
    </main>

    <hr>

    <!-- Footer -->
    <footer>
        <p>&copy; 2026 App Film. Dibuat untuk belajar PHP.</p>
    </footer>

</body>

</html>
Penjelasan:
• <header> — bagian atas halaman, berisi judul aplikasi
• <nav> — navigasi/menu untuk berpindah antar halaman
• <main> — konten utama halaman
• <footer> — bagian bawah halaman
• isset($_POST['submit']) — mengecek apakah form sudah dikirim
• INSERT INTO — query SQL untuk menambahkan data baru
• htmlspecialchars() — mencegah karakter HTML berbahaya
• action="" — form dikirim ke halaman yang sama
• method="post" — data dikirim secara tersembunyi
• required — field wajib diisi

Membuat Halaman Lihat Data

lihat-data.php

Halaman ini menampilkan semua data film yang tersimpan di database dalam bentuk tabel. Di sini juga terdapat tombol Edit dan Hapus untuk setiap data.

Buat file baru: lihat-data.php

Ketik seluruh code berikut ke dalam file lihat-data.php:

<!DOCTYPE html>
<html lang="id">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Lihat Data - App Film</title>
</head>

<body>

    <!-- Header -->
    <header>
        <h1>App Film</h1>
        <p>Aplikasi Manajemen Data Film</p>
    </header>

    <!-- Navbar -->
    <nav>
        <a href="index.php">Tambah Film</a> |
        <a href="lihat-data.php"><b>Lihat Data</b></a>
    </nav>

    <hr>

    <!-- Konten Utama -->
    <main>
        <h2>Daftar Data Film</h2>

        <?php if (isset($_GET['pesan'])): ?>
            <?php if ($_GET['pesan'] === 'update_berhasil'): ?>
                <p>Data film berhasil diupdate!</p>
            <?php elseif ($_GET['pesan'] === 'hapus_berhasil'): ?>
                <p>Data film berhasil dihapus!</p>
            <?php endif; ?>
        <?php endif; ?>

        <?php
        include 'koneksi.php';
        $query = "SELECT * FROM data_film";
        $result = mysqli_query($koneksi, $query);

        if (mysqli_num_rows($result) > 0) {
            echo "<table border='1' cellpadding='8' cellspacing='0'>
                    <tr>
                        <th>No</th>
                        <th>Judul Film</th>
                        <th>Tahun Rilis</th>
                        <th>Aksi</th>
                    </tr>";

            $no = 1;
            while ($row = mysqli_fetch_assoc($result)) {
                echo "<tr>
                        <td>" . $no++ . "</td>
                        <td>"
                    . htmlspecialchars($row['judul'])
                    . "</td>
                        <td>"
                    . htmlspecialchars($row['tahun'])
                    . "</td>
                        <td>
                            <a href='edit-data.php?id="
                    . $row['id']
                    . "'>Edit</a> | 
                            <a href='hapus-data.php?id="
                    . $row['id']
                    . "' onclick=\"return confirm(
                        'Apakah Anda yakin ingin menghapus film ini?'
                    )\">Hapus</a>
                        </td>
                      </tr>";
            }
            echo "</table>";
        } else {
            echo "<p>Belum ada data film."
               . " <a href='index.php'>"
               . "Tambah film pertama →"
               . "</a></p>";
        }

        mysqli_close($koneksi);
        ?>
    </main>

    <hr>

    <!-- Footer -->
    <footer>
        <p>&copy; 2026 App Film. Dibuat untuk belajar PHP.</p>
    </footer>

</body>

</html>
Penjelasan:
• SELECT * FROM data_film — mengambil semua data dari tabel
• mysqli_num_rows() — menghitung jumlah baris data
• mysqli_fetch_assoc() — mengambil satu baris data sebagai array
• while — perulangan untuk menampilkan semua baris data
• $no++ — nomor urut yang bertambah otomatis
• onclick="return confirm(...)" — menampilkan dialog konfirmasi sebelum menghapus
• $_GET['pesan'] — menampilkan notifikasi dari redirect edit/hapus

Membuat Halaman Edit Film

edit-data.php

Halaman ini berisi form untuk mengubah data film yang sudah ada. Data film yang akan diedit diambil berdasarkan id yang dikirim melalui URL.

Buat file baru: edit-data.php

Penting! File ini berbeda dari file sebelumnya. Code PHP untuk proses update harus ditulis di paling atas, sebelum code HTML. Ini karena kita menggunakan header() untuk redirect, yang harus dipanggil sebelum ada output HTML.

Ketik seluruh code berikut ke dalam file edit-data.php:

<?php
include 'koneksi.php';

// Proses update data (taruh di atas sebelum HTML agar bisa redirect)
if (isset($_POST['submit'])) {
    $id = $_POST['id'];
    $judul = $_POST['judul'];
    $tahun = $_POST['tahun'];

    // Query untuk mengupdate data film
    $query = "UPDATE data_film
               SET judul = '$judul',
                   tahun = '$tahun'
               WHERE id = '$id'";
    if (mysqli_query($koneksi, $query)) {
        header("Location: lihat-data.php?pesan=update_berhasil");
        exit;
    } else {
        $error = mysqli_error($koneksi);
    }
}
?>
<!DOCTYPE html>
<html lang="id">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Edit Film - App Film</title>
</head>

<body>

    <!-- Header -->
    <header>
        <h1>App Film</h1>
        <p>Aplikasi Manajemen Data Film</p>
    </header>

    <!-- Navbar -->
    <nav>
        <a href="index.php">Tambah Film</a> |
        <a href="lihat-data.php">Lihat Data</a>
    </nav>

    <hr>

    <!-- Konten Utama -->
    <main>
        <h2>Edit Data Film</h2>

        <?php if (isset($error)): ?>
            <p>Error: <?php echo $error; ?></p>
        <?php endif; ?>

        <?php
        if (isset($_GET['id'])) {
            $id = $_GET['id'];
            $query = "SELECT * FROM data_film
                       WHERE id = '$id'";
            $result = mysqli_query($koneksi, $query);
            if (mysqli_num_rows($result) > 0) {
                $row = mysqli_fetch_assoc($result);
        ?>
                <form action="" method="post">
                    <input type="hidden"
                           name="id"
                           value="<?php echo $row['id']; ?>">

                    <p>
                        <label for="judul">Judul Film:</label><br>
                        <input type="text"
                               id="judul"
                               name="judul"
                               value="<?php echo htmlspecialchars($row['judul']); ?>"
                               required>
                    </p>

                    <p>
                        <label for="tahun">Tahun Rilis:</label><br>
                        <input type="number"
                               id="tahun"
                               name="tahun"
                               value="<?php echo htmlspecialchars($row['tahun']); ?>"
                               required>
                    </p>

                    <p>
                        <input type="submit"
                               name="submit"
                               value="💾 Update Film">
                        <a href="lihat-data.php">Batal</a>
                    </p>
                </form>
        <?php
            } else {
                echo "<p>Data film tidak ditemukan."
                   . " <a href='lihat-data.php'>"
                   . "Kembali →</a></p>";
            }
        } else {
            echo "<p>ID film tidak valid."
               . " <a href='lihat-data.php'>"
               . "Kembali →</a></p>";
        }

        mysqli_close($koneksi);
        ?>
    </main>

    <hr>

    <!-- Footer -->
    <footer>
        <p>&copy; 2026 App Film. Dibuat untuk belajar PHP.</p>
    </footer>

</body>

</html>
Penjelasan:
• header("Location: ...") — mengarahkan (redirect) browser ke halaman lain
• exit — menghentikan eksekusi code setelah redirect
• $_GET['id'] — mengambil id film dari URL (contoh: edit-data.php?id=1)
• input type="hidden" — menyimpan id yang tidak terlihat oleh user
• value="<?php echo ... ?>" — mengisi form dengan data yang sudah ada
• Tombol "Batal" mengarahkan kembali ke halaman lihat data

Membuat Halaman Hapus Film

hapus-data.php

File ini tidak memiliki tampilan HTML. Fungsinya hanya menghapus data dari database, lalu langsung mengarahkan (redirect) kembali ke halaman lihat data.

Buat file baru: hapus-data.php

Ketik seluruh code berikut ke dalam file hapus-data.php:

<?php
include 'koneksi.php';

if (isset($_GET['id'])) {
    $id = $_GET['id'];
    $query = "DELETE FROM data_film WHERE id = '$id'";
    if (mysqli_query($koneksi, $query)) {
        header(
            "Location: lihat-data.php?pesan=hapus_berhasil"
        );
        exit;
    } else {
        echo "Error: " . mysqli_error($koneksi);
    }
} else {
    header("Location: lihat-data.php");
    exit;
}

mysqli_close($koneksi);
?>
Penjelasan:
• DELETE FROM data_film WHERE id = ... — query SQL untuk menghapus data berdasarkan id
• Setelah hapus berhasil, langsung redirect ke lihat-data.php dengan pesan sukses
• Jika tidak ada id, langsung redirect ke halaman lihat data (mencegah akses langsung)
• File ini tidak memiliki HTML karena user tidak perlu melihat halaman ini

Uji Coba Aplikasi

Setelah semua file selesai dibuat, saatnya menguji aplikasi!

8.1 Pastikan Laragon Berjalan

  1. Buka Laragon
  2. Klik tombol "Start All"
  3. Pastikan Apache dan MySQL berwarna hijau (aktif)

8.2 Buka Aplikasi di Browser

  1. Buka browser (Chrome, Firefox, dll)
  2. Ketik di address bar: http://localhost/app-film/
  3. Tekan Enter

8.3 Uji Fitur Tambah Film

  1. Di halaman utama, isi Judul Film (contoh: "Avengers: Endgame")
  2. Isi Tahun Rilis (contoh: 2019)
  3. Klik tombol "Tambah Film"
  4. Pastikan muncul pesan "Data film berhasil ditambahkan!"
  5. Tambahkan 2-3 film lagi untuk testing

8.4 Uji Fitur Lihat Data

  1. Klik link "Lihat Data" di navbar
  2. Pastikan semua film yang sudah ditambahkan muncul dalam tabel
  3. Periksa kolom No, Judul Film, Tahun Rilis, dan Aksi

8.5 Uji Fitur Edit Film

  1. Di halaman Lihat Data, klik "Edit" pada salah satu film
  2. Ubah judul atau tahun rilis
  3. Klik tombol "💾 Update Film"
  4. Pastikan otomatis kembali ke halaman Lihat Data
  5. Pastikan muncul pesan "Data film berhasil diupdate!"
  6. Periksa apakah data sudah berubah di tabel

8.6 Uji Fitur Hapus Film

  1. Di halaman Lihat Data, klik "Hapus" pada salah satu film
  2. Akan muncul dialog konfirmasi, klik "OK"
  3. Pastikan otomatis kembali ke halaman Lihat Data
  4. Pastikan muncul pesan "Data film berhasil dihapus!"
  5. Periksa apakah data sudah hilang dari tabel
Troubleshooting:
• Halaman blank/putih? — Cek apakah ada typo di code PHP (terutama tanda kutip dan titik koma)
• Error koneksi database? — Pastikan nama database db.film sudah benar dan MySQL sudah aktif
• Tabel tidak muncul? — Pastikan sudah membuat tabel data_film di phpMyAdmin
• Data tidak tersimpan? — Cek nama kolom di query SQL harus sama persis dengan nama kolom di tabel
