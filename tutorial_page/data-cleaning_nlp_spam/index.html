03

Case Folding

Mengubah semua teks menjadi huruf kecil (lowercase)

Penjelasan

TF-IDF bersifat case-sensitive — kata "Selamat", "SELAMAT", dan "selamat" akan dianggap sebagai 3 kata berbeda. Ini menyebabkan fitur yang redundan dan mengurangi akurasi model. Dengan case folding, semua variasi menjadi satu kata yang sama: selamat.

Kode Python

Python 
# Case folding — ubah semua teks ke lowercase
df['Pesan'] = df['Pesan'].str.lower()

print(df['Pesan'].head(3))

04

Cleaning — Hapus Noise

Menghapus URL, angka, tanda baca, emoji, dan karakter khusus

Penjelasan

SMS spam sering mengandung URL, nomor telepon, angka promosi, emoji, dan karakter khusus yang tidak membawa informasi linguistik untuk TF-IDF. Elemen-elemen ini hanya menambah noise pada fitur dan memperbesar dimensi vocabulary tanpa meningkatkan kemampuan diskriminatif model Naive Bayes.

Kode Python

Python 
import re

def clean_text(text):
    # Hapus URL
    text = re.sub(r'http\S+|www\.\S+', '', text)
    # Hapus mention & hashtag
    text = re.sub(r'@\w+|#\w+', '', text)
    # Hapus angka
    text = re.sub(r'\d+', '', text)
    # Hapus tanda baca & karakter khusus
    text = re.sub(r'[^\w\s]', '', text)
    # Hapus whitespace berlebih
    text = re.sub(r'\s+', ' ', text).strip()
    return text

df['Pesan'] = df['Pesan'].apply(clean_text)
print(df['Pesan'].head(3))
▶ Output 
0    plg yth simcard anda mendptkan bonus poin plus...
1            iya ih ko sedih sih gtau kapan lg ke bandung
2       kalau mau bikin modelcontroller mending per apa y
Name: Pesan, dtype: object

05

Tokenisasi

Memecah kalimat menjadi kumpulan kata (token)

Penjelasan

Tokenisasi adalah proses memecah teks menjadi unit-unit kecil yang disebut token (biasanya kata). Ini adalah langkah fundamental dalam NLP karena semua proses selanjutnya (normalisasi slang, stopword removal, stemming) bekerja pada level token. Untuk bahasa Indonesia, kita bisa menggunakan str.split() karena pemisah antar kata sudah cukup jelas (spasi).

Kode Python

Python 
# Tokenisasi — pecah kalimat menjadi list kata
df['Pesan_Tokens'] = df['Pesan'].str.split()

06

Normalisasi Kata Gaul & Singkatan

Mengubah kata informal/singkatan ke bentuk baku (yg → yang, tdk → tidak)

Mengapa Ini Penting?

Teks SMS Indonesia sangat informal — penuh dengan singkatan (yg, tdk, utk) dan kata gaul (gak, aja, banget). Tanpa normalisasi, TF-IDF akan menganggap yg dan yang sebagai dua kata berbeda — padahal artinya sama. Ini menyebabkan:
• Vocabulary membengkak dengan variasi kata yang redundan
• Frekuensi kata terpecah sehingga bobot TF-IDF tidak akurat
• Naive Bayes kehilangan pola penting karena probabilitas kata terdilusi

Kode Python

  1. Buat kamus (dictionary) kata gaul & singkatan ke bentuk baku:

    Python 
    # Kamus normalisasi kata gaul & singkatan Indonesia
slang_dict = {
    'yg': 'yang',     'tdk': 'tidak',    'gak': 'tidak',
    'gk': 'tidak',     'ga': 'tidak',     'ngga': 'tidak',
    'dgn': 'dengan',   'dg': 'dengan',    'utk': 'untuk',
    'dr': 'dari',      'sy': 'saya',     'sdh': 'sudah',
    'udh': 'sudah',    'blm': 'belum',   'bs': 'bisa',
    'krn': 'karena',   'tp': 'tapi',     'jg': 'juga',
    'lg': 'lagi',      'aja': 'saja',    'bgt': 'sangat',
    'sm': 'sama',      'klo': 'kalau',   'kalo': 'kalau',
    'gmn': 'bagaimana', 'dmn': 'dimana',
    'skrg': 'sekarang', 'hrs': 'harus',
    'org': 'orang',    'trs': 'terus',
    'msh': 'masih',    'dl': 'dulu',
    'emang': 'memang', 'pake': 'pakai',
    'sampe': 'sampai', 'kayak': 'seperti',
    'gitu': 'begitu',  'gini': 'begini',
    'dpt': 'dapat',    'hub': 'hubungi',
    'nmr': 'nomor',    'tlp': 'telepon',
    'gtau': 'tidak tahu',
    'makasih': 'terima kasih',
    'trmks': 'terima kasih',
    # ... tambahkan sesuai kebutuhan
}

print(f'Jumlah kata dalam kamus: {len(slang_dict)}')
    ▶ Output 
    Jumlah kata dalam kamus: 65

  2. Terapkan normalisasi pada setiap token:

    Python 
    def normalize_slang(tokens):
    return [slang_dict.get(word, word) for word in tokens]

df['Pesan_Tokens'] = df['Pesan_Tokens'].apply(normalize_slang)

# Lihat perbandingan sebelum vs sesudah
print(df['Pesan_Tokens'].head(3))
    ▶ Output

Perhatian: Kamus slang ini bersifat manual dan tidak lengkap. Anda bisa memperkaya kamus dengan menganalisis kata-kata unik di dataset:
all_words = [w for tokens in df['Pesan_Tokens'] for w in tokens]
pd.Series(all_words).value_counts().tail(50)

Atau menggunakan kamus slang publik dari repository seperti kamus-alay di GitHub.

Tips: Fungsi slang_dict.get(word, word) artinya: jika kata ada di kamus → kembalikan bentuk baku, jika tidak ada → kembalikan kata aslinya. Jadi kata yang sudah baku tidak berubah.

07

Stopword Removal

Menghapus kata-kata umum yang tidak bermakna diskriminatif

Penjelasan

Stopwords adalah kata-kata umum seperti "yang", "dan", "di", "ke", "ini", "itu" yang muncul di hampir semua dokumen. Dalam konteks TF-IDF, kata-kata ini memiliki IDF rendah (karena muncul di banyak dokumen) sehingga kontribusi mereka terhadap vektor fitur sangat kecil. Menghapusnya akan:
• Mengurangi dimensi fitur (vocabulary lebih kecil)
• Mempercepat proses training
• Meningkatkan fokus pada kata-kata diskriminatif (misal: "hadiah", "gratis" untuk spam)

Kode Python

  1. Install & import library NLTK untuk stopwords bahasa Indonesia:

    Python 
    import nltk
nltk.download('stopwords')
from nltk.corpus import stopwords

stop_words = set(stopwords.words('indonesian'))
print(f'Jumlah stopwords: {len(stop_words)}')
print(sorted(list(stop_words))[:20])
    ▶ Output 
    [nltk_data] Downloading package stopwords to /root/nltk_data...
[nltk_data]   Package stopwords is already up-to-date!

Jumlah stopwords: 758
['ada', 'adalah', 'adanya', 'adapun', 'agak', 'agaknya',
 'agar', 'akan', 'akankah', 'akhir', 'akhiri', 'akhirnya',
 'aku', 'akulah', 'amat', 'amatlah', 'anda', 'andalah',
 'antar', 'antara']

  2. Hapus stopwords dari setiap token:

    Python 
    def remove_stopwords(tokens):
    return [word for word in tokens if word not in stop_words]

df['Pesan_Tokens'] = df['Pesan_Tokens'].apply(remove_stopwords)
print(df['Pesan_Tokens'].head(3))

08

Stemming

Mengembalikan kata ke bentuk dasar (root word)

Penjelasan

Stemming adalah proses menghilangkan imbuhan (awalan, akhiran, sisipan) untuk mendapatkan kata dasar. Misalnya: mendapatkan → dapat, penawaran → tawar. Untuk bahasa Indonesia, kita menggunakan library Sastrawi yang memahami aturan morfologi bahasa Indonesia.

Dalam konteks TF-IDF, stemming mengurangi dimensi fitur dengan menggabungkan variasi kata yang bermakna sama ke satu token. Ini membantu Naive Bayes belajar pola yang lebih general.

Kode Python

  1. Install & inisialisasi Sastrawi stemmer:

    Terminal 
    pip install Sastrawi

  2. Terapkan stemming pada token:

    Python 
    from Sastrawi.Stemmer.StemmerFactory import StemmerFactory

# Buat stemmer (cukup sekali)
factory = StemmerFactory()
stemmer = factory.createStemmer()

def stem_tokens(tokens):
    return [stemmer.stem(word) for word in tokens]

df['Pesan_Tokens'] = df['Pesan_Tokens'].apply(stem_tokens)
print(df['Pesan_Tokens'].head(3))
    ▶ Output 
    0    [plg, yth, simcard, dapat, bonus, poin, plus, ...
1                    [ih, ko, sedih, sih, tahu, kapan, bandung]
2                         [bikin, modelcontroller, mending, apa]
Name: Pesan_Tokens, dtype: object

Contoh Hasil Stemming

Kata Asli → Hasil Stemming
mendapatkan → dapat
penawaran → tawar
menghubungi → hubung
pemenang → menang
selamat → selamat

Catatan: Proses stemming Sastrawi bisa memakan waktu karena menganalisis setiap kata satu per satu. Untuk dataset besar, pertimbangkan menggunakan caching atau parallel processing.

Gabung Token Kembali

Menggabungkan list token menjadi string kalimat kembali

Penjelasan

Setelah selesai preprocessing pada level token, kita perlu menggabungkan kembali token menjadi string. Ini karena TfidfVectorizer dari scikit-learn menerima input berupa string, bukan list. Kita menggunakan ' '.join() untuk menyatukan token dengan spasi sebagai pemisah.

Kode Python

Python 
# Gabung token kembali menjadi string
df['Pesan_Clean'] = df['Pesan_Tokens'].apply(lambda x: ' '.join(x))

# Hapus kolom token sementara (opsional)
df.drop(columns=['Pesan_Tokens'], inplace=True)

print(df[['Pesan', 'Pesan_Clean']].head(3))

                                          Pesan_Clean
0  plg yth simcard dapat bonus poin plus drptindo...

10

Label Encoding

Mengubah label kategorikal menjadi numerik

Penjelasan

Model Naive Bayes di scikit-learn membutuhkan label dalam format numerik. Kita perlu mengubah label spam dan ham menjadi angka: spam → 1, ham → 0. Kita menggunakan map() untuk mapping yang eksplisit dan mudah dipahami.

Kode Python

Python 
# Label encoding: spam → 1, ham → 0
df['Label'] = df['Kategori'].map({'spam': 1, 'ham': 0})

print(df[['Kategori', 'Label']].head(6))
print(f'\nDistribusi label numerik:')
print(df['Label'].value_counts())
▶ Output

1      ham      0
2      ham      0
3      ham      0
4     spam      1
5     spam      1

Label
1    530
0    528
Name: count, dtype: int64

Hasil Encoding

Kategori → Label
spam → 1
ham → 0

Mengapa manual map? Bisa juga menggunakan LabelEncoder dari scikit-learn, tetapi map() lebih eksplisit — kita tahu persis mapping-nya: spam=1 (positif/target), ham=0 (negatif/normal).
