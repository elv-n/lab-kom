Tutorial: Perhitungan Nilai Siswa

Belajar membuat aplikasi web sederhana menggunakan PHP, HTML, dan CSS.

1. Pendahuluan

Pada tutorial ini, kita akan membuat aplikasi Perhitungan Nilai Siswa yang dapat:

  • Menerima input data siswa (Nama, Kelas, Jurusan)
  • Menerima input nilai (Tugas, UTS, UAS)
  • Menghitung Nilai Akhir dengan rumus: Tugas 30% + UTS 35% + UAS 35%
  • Menampilkan status LULUS atau TIDAK LULUS (batas nilai 75)
Yang dibutuhkan: Laragon (atau XAMPP), browser, dan text editor (Notepad / VS Code).

2. Struktur Folder

Buat folder bernama xxx di dalam folder www (Laragon) atau htdocs (XAMPP), lalu buat file-file berikut:

xxx/
   proses.php    -- logika PHP (perhitungan)
   index.php     -- tampilan HTML
   style.css     -- styling CSS
   logo.png      -- gambar logo

3. Langkah-langkah

1 Buat file proses.php

File ini berisi logika PHP untuk mengambil data dari form dan menghitung nilai akhir.

proses.php 
<?php
// ========================================
// PHP: Mengolah data dari form (POST)
// ========================================

// Variabel awal (kosong)
$nama         = '';
$kelas        = '';
$jurusan      = '';
$tugas        = '';
$uts          = '';
$uas          = '';
$nilai_akhir  = '';
$status       = '';
$status_class = '';

// Cek apakah tombol Hitung ditekan
if (isset($_POST['hitung'])) {
    // Ambil data dari form
    $nama    = htmlspecialchars($_POST['nama']);
    $kelas   = htmlspecialchars($_POST['kelas']);
    $jurusan = htmlspecialchars($_POST['jurusan']);
    $tugas   = floatval($_POST['tugas']);
    $uts     = floatval($_POST['uts']);
    $uas     = floatval($_POST['uas']);

    // Hitung Nilai Akhir: Tugas 30%, UTS 35%, UAS 35%
    $nilai_akhir = ($tugas * 0.3) + ($uts * 0.35) + ($uas * 0.35);
    $nilai_akhir = number_format($nilai_akhir, 2);

    // Tentukan status lulus atau tidak
    if ($nilai_akhir >= 75) {
        $status       = 'LULUS';
        $status_class = 'status-lulus';
    } else {
        $status       = 'TIDAK LULUS';
        $status_class = 'status-gagal';
    }
}
?>

Penjelasan kode:

KodeFungsi
$_POST['nama']Mengambil data yang dikirim dari form (method POST)
isset($_POST['hitung'])Mengecek apakah tombol "Hitung" sudah ditekan
htmlspecialchars()Mengamankan input agar tidak ada kode berbahaya
floatval()Mengubah input teks menjadi angka desimal
number_format($score, 2)Memformat angka menjadi 2 angka di belakang koma

4. Cara Menjalankan

  1. Pastikan Laragon sudah dijalankan (Start All)
  2. Simpan semua file di folder C:\laragon\www\xxx\
  3. Buka browser, ketik: http://localhost/xxx/
  4. Isi form, lalu klik tombol "Hitung Nilai"
  5. Lihat hasilnya di bagian Output
Tips: Jika menggunakan XAMPP, simpan folder xxx di dalam C:\xampp\htdocs\.

5. Alur Program

Berikut adalah alur kerja aplikasi dari awal sampai akhir:

  1. User membuka http://localhost/xxx/
  2. Browser menampilkan index.php (yang otomatis memanggil proses.php)
  3. User mengisi form lalu klik tombol Hitung Nilai
  4. Data dikirim ke server menggunakan method POST
  5. proses.php menerima data via $_POST, lalu menghitung Nilai Akhir
  6. Hasil ditampilkan di bagian Output (Nama, Kelas, Jurusan, Nilai Akhir, Status)
