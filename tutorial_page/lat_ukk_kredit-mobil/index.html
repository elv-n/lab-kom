01

Membuat header.php

Struktur HTML, meta tag, dan aset eksternal

Penjelasan

File header.php adalah fondasi dari setiap halaman web. File ini berisi deklarasi <!DOCTYPE html>, tag <head> yang memuat meta tag, CSS Bootstrap, ikon, Google Fonts, dan link ke custom stylesheet. File ini dibuka dengan tag <body> dan tidak ditutup — penutupan dilakukan di footer.php.

Mengapa dipisah? Dengan memisahkan header ke file sendiri, kita menghindari duplikasi kode. Setiap halaman cukup melakukan include 'header.php' untuk mendapatkan struktur HTML yang konsisten.

header.php

header.php 
<!DOCTYPE html>
<html lang="id">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>AutoKredit - Simulasi Kredit Mobil</title>

    <!-- Custom CSS -->
    <link rel="stylesheet" href="style.css">

Membuat form.php

Form input data kredit mobil

Penjelasan

File form.php berisi form HTML yang menerima 3 input dari user: Harga Mobil, DP (persen), dan Tenor (tahun). Form menggunakan method POST dan mengirim data ke halaman yang sama. Di bagian bawah, file ini meng-include proses.php untuk memproses data saat form disubmit.

Membuat proses.php

Logika perhitungan angsuran kredit

Penjelasan

File proses.php adalah otak dari aplikasi ini. File ini memproses data yang dikirim dari form, melakukan validasi input, menghitung angsuran kredit menggunakan rumus flat rate, dan menampilkan hasil melalui file hasil.php.

Rumus: Angsuran = ((Harga Mobil + Bunga 20%) - DP) / Jumlah Bulan

proses.php

proses.php 
<?php
// Cek apakah form sudah disubmit
if (isset($_POST['hitung'])) {

    // 1. Ambil data input dari form
    $harga_mobil = floatval($_POST['harga_mobil']);
    $dp_persen   = floatval($_POST['dp_persen']);
    $tenor_tahun = intval($_POST['tenor_tahun']);

    // 2. Validasi input
    $error = '';
    if ($harga_mobil <= 0) {
        $error = 'Harga mobil harus lebih dari 0!';
    } // ... validasi lainnya

    if ($error) {
        echo '<div class="alert alert-danger">' . $error . '</div>';
    } else {
        // 3. Proses Perhitungan
        $persen_bunga = 20;
        $bunga = $harga_mobil * ($persen_bunga / 100);
        $dp_nominal = $harga_mobil * ($dp_persen / 100);
        $jumlah_bulan = $tenor_tahun * 12;
        
        $angsuran = (($harga_mobil + $bunga) - $dp_nominal) / $jumlah_bulan;

        // 4. Tampilkan hasil
        include 'hasil.php';
    }
}
?>

Membuat hasil.php

Tampilan tabel hasil perhitungan angsuran

Penjelasan

File hasil.php menampilkan hasil perhitungan dalam format tabel yang rapi. File ini menggunakan variabel-variabel yang sudah dihitung di proses.php. Baris terakhir (angsuran per bulan) diberi highlight hijau sebagai highlight utama.

hasil.php

hasil.php 
<div class="card mt-4 border-success">

            <tbody>
                <tr>
                    <td class="fw-semibold">Harga Mobil</td>
                    <td>Rp. <?= number_format($harga_mobil, 0, ',', '.') ?></td>
                </tr>
                <!-- ... baris DP, Tenor, Bunga ... -->
                <tr class="table-success">
                    <td class="fw-bold fs-5">Jumlah Angsuran</td>
                    <td class="fw-bold fs-5 text-success">
                        Rp. <?= number_format(round($angsuran), 0, ',', '.') ?> / Bulan
                    </td>
                </tr>
            </tbody>
        </table>
    </div>
</div>
