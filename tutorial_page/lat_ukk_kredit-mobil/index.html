1

Membuat header.php

Struktur HTML, meta tag, dan aset eksternal

File header.php adalah fondasi dari setiap halaman web. File ini berisi deklarasi <!DOCTYPE html>, tag <head> yang memuat meta tag, CSS Bootstrap, ikon, Google Fonts, dan link ke custom stylesheet. File ini dibuka dengan tag <body> dan tidak ditutup — penutupan dilakukan di footer.php.

Mengapa dipisah? Dengan memisahkan header ke file sendiri, kita menghindari duplikasi kode. Setiap halaman cukup melakukan include 'header.php' untuk mendapatkan struktur HTML yang konsisten.

header.php PHP 
<!DOCTYPE html>
<html lang="id">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>AutoKredit - Simulasi Kredit Mobil</title>
    <!-- Bootstrap 5 CSS CDN -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <!-- Bootstrap Icons -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.css" rel="stylesheet">
    <!-- Google Fonts -->
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
    <!-- Custom CSS -->
    <link rel="stylesheet" href="style.css">
</head>

<body>

Penjelasan Kode

  • <!DOCTYPE html> — Memberitahu browser bahwa ini dokumen HTML5.
  • lang="id" — Menandai bahasa halaman adalah Bahasa Indonesia.
  • meta charset="UTF-8" — Mendukung karakter Unicode (huruf, simbol, emoji).
  • meta viewport — Membuat halaman responsive di perangkat mobile.
  • Bootstrap 5 CSS — Framework CSS untuk layout dan komponen siap pakai.
  • Bootstrap Icons — Library ikon vektor gratis dari Bootstrap.
  • Google Fonts (Inter) — Font modern yang bersih dan mudah dibaca.
  • style.css — File CSS kustom kita untuk styling tambahan.

Penjelasan Kode

  • navbar-expand-lg — Menu horizontal di layar ≥ 992px, hamburger di bawahnya.
  • navbar-dark bg-dark — Tema gelap dengan teks putih.
  • sticky-top — Navbar menempel di atas saat halaman di-scroll.
  • navbar-toggler — Tombol hamburger yang muncul di layar kecil.
  • data-bs-toggle="collapse" — Atribut Bootstrap untuk toggle menu.
  • ms-auto — Margin start auto → mendorong menu ke kanan.
  • bi bi-house-door — Ikon dari Bootstrap Icons.
  • Setiap href="#..." mengarah ke section ID di halaman (anchor link).

Membuat proses.php

Logika perhitungan angsuran kredit

File proses.php adalah otak dari aplikasi ini. File ini memproses data yang dikirim dari form, melakukan validasi input, menghitung angsuran kredit menggunakan rumus flat rate, dan menampilkan hasil melalui file hasil.php.

Rumus Perhitungan Angsuran
Angsuran = ((Harga Mobil + Bunga 20%) - DP) / Jumlah Bulan
proses.php PHP 
<?php
/**
 * ==========================================================
 * FILE: proses.php
 * FUNGSI: Memproses perhitungan angsuran kredit mobil
 * ==========================================================
 *
 * ALGORITMA PERHITUNGAN:
 * ----------------------
 * 1. Menerima input dari form (POST method):
 *    - harga_mobil : harga mobil dalam Rupiah (angka)
 *    - dp_persen   : persentase uang muka / DP (0-100)
 *    - tenor_tahun : lama cicilan dalam tahun (angka)
 *
 * 2. Validasi input:
 *    - Harga mobil harus > 0
 *    - DP harus antara 0% - 100%
 *    - Tenor harus minimal 1 tahun
 *
 * 3. Proses perhitungan:
 *    a. bunga       = harga_mobil × 20 / 100
 *    b. dp_nominal  = harga_mobil × dp_persen / 100
 *    c. jumlah_bulan = tenor_tahun × 12
 *    d. angsuran    = ((harga_mobil + bunga) - dp_nominal) / jumlah_bulan
 *
 * 4. Tampilkan hasil ke user
 *
 * RUMUS UTAMA:
 *   Angsuran = ((Harga Mobil + Bunga 20%) - DP) / Jumlah Bulan
 * ==========================================================
 */

// Cek apakah form sudah disubmit (tombol "hitung" ditekan)
if (isset($_POST['hitung'])) {

    // ===== LANGKAH 1: Ambil data input dari form =====
    $harga_mobil = floatval($_POST['harga_mobil']);  // Konversi ke angka desimal
    $dp_persen   = floatval($_POST['dp_persen']);     // Konversi ke angka desimal
    $tenor_tahun = intval($_POST['tenor_tahun']);     // Konversi ke angka bulat

    // ===== LANGKAH 2: Validasi input =====
    $error = '';
    if ($harga_mobil <= 0) {
        $error = 'Harga mobil harus lebih dari 0!';
    } elseif ($dp_persen < 0 || $dp_persen > 100) {
        $error = 'DP harus antara 0% - 100%!';
    } elseif ($tenor_tahun <= 0) {
        $error = 'Tenor harus minimal 1 tahun!';
    }

    // Jika ada error, tampilkan pesan
    if ($error) {
        echo '<div class="alert alert-danger mt-4" role="alert">';
        echo '<i class="bi bi-exclamation-triangle me-2"></i>' . $error;
        echo '</div>';
    } else {

        // ===== LANGKAH 3: Proses Perhitungan =====

        // a. Hitung bunga (20% dari harga mobil)
        $persen_bunga = 20;
        $bunga = $harga_mobil * ($persen_bunga / 100);

        // b. Hitung nominal DP dalam Rupiah
        $dp_nominal = $harga_mobil * ($dp_persen / 100);

        // c. Konversi tenor dari tahun ke bulan
        $jumlah_bulan = $tenor_tahun * 12;

        // d. Hitung angsuran per bulan
        //    Rumus: ((Harga Mobil + Bunga) - DP) / Jumlah Bulan
        $angsuran = (($harga_mobil + $bunga) - $dp_nominal) / $jumlah_bulan;

        // ===== LANGKAH 4: Tampilkan hasil =====
        // Menggunakan include untuk memisahkan tampilan hasil
        include 'hasil.php';
    }
}
?>

Penjelasan Kode

  • isset($_POST['hitung']) — Mengecek apakah tombol "Hitung" sudah ditekan.
  • floatval() — Mengkonversi string input menjadi angka desimal (float).
  • intval() — Mengkonversi string input menjadi angka bulat (integer).
  • Validasi — Memastikan semua input valid sebelum dihitung (harga > 0, DP 0-100%, tenor ≥ 1).
  • Bunga Flat 20% — Bunga dihitung sekali dari harga mobil, bukan bunga menurun.
  • $jumlah_bulan = $tenor_tahun * 12 — Mengubah tenor tahun ke bulan.
  • Rumus angsuran — Total pinjaman (harga + bunga - DP) dibagi jumlah bulan.
  • include 'hasil.php' — Memisahkan tampilan hasil ke file tersendiri (separation of concerns).

Membuat hasil.php

Tampilan tabel hasil perhitungan angsuran

File hasil.php menampilkan hasil perhitungan dalam format tabel yang rapi. File ini menggunakan variabel-variabel yang sudah dihitung di proses.php seperti $harga_mobil, $dp_nominal, $bunga, dan $angsuran. Baris terakhir (angsuran per bulan) diberi highlight hijau sebagai highlight utama.

hasil.php PHP 
<!-- ===================== HASIL PERHITUNGAN ===================== -->

</div>

Penjelasan Kode

  • number_format($harga_mobil, 0, ',', '.') — Memformat angka menjadi format Rupiah (titik pemisah ribuan, tanpa desimal).
  • round($angsuran) — Membulatkan angsuran ke bilangan bulat terdekat.
  • <?= ... ?> — Shorthand PHP untuk <?php echo ... ?>.
  • table-bordered table-striped — Tabel dengan border dan baris bergaris-garis (zebra stripes).
  • table-success — Memberi background hijau pada baris hasil utama.
  • border-success — Memberi border hijau pada card.
  • bg-success text-white — Header card berwarna hijau dengan teks putih.

Membuat index.php

Entry point — menggabungkan semua file

File index.php adalah entry point atau titik masuk utama website. File ini menggunakan fungsi include PHP untuk menggabungkan semua file komponen menjadi satu halaman HTML yang utuh. Tidak ada logika rumit di file ini — hanya urutan include yang menentukan susunan halaman.

Selesai! Setelah membuat file ini, project Anda sudah lengkap. Buka http://localhost/lat-ukk/ di browser untuk melihat hasilnya.

index.php PHP 
<?php
/**
 * ==========================================================
 * FILE: index.php (Halaman Utama)
 * ==========================================================
 *
 * File ini adalah entry point / halaman utama dari website
 * simulasi kredit mobil AutoKredit.
 *
 * STRUKTUR FILE:
 * - header.php  → Tag HTML, <head>, CSS, dan font
 * - navbar.php  → Menu navigasi (Beranda, Tentang, Kontak)
 * - slider.php  → Gambar slider / carousel
 * - form.php    → Form input kredit (Harga, DP, Tenor)
 *   └ proses.php → Logika perhitungan angsuran (di-include oleh form.php)
 *     └ hasil.php → Tampilan tabel hasil perhitungan (di-include oleh proses.php)
 * - tentang.php → Section Tentang Perusahaan
 * - kontak.php  → Section Kontak Perusahaan
 * - footer.php  → Footer dan Bootstrap JS
 *
 * CARA KERJA:
 * PHP include() digunakan untuk menggabungkan semua file
 * menjadi satu halaman HTML yang utuh.
 * ==========================================================
 */
?>

<?php include 'header.php'; ?>

<?php include 'navbar.php'; ?>

<?php include 'slider.php'; ?>

<?php include 'form.php'; ?>

<?php include 'tentang.php'; ?>

<?php include 'kontak.php'; ?>

<?php include 'footer.php'; ?>

Penjelasan Kode

  • include 'header.php' — Memasukkan isi file header.php ke posisi ini.
  • Urutan include menentukan urutan tampilan di halaman (atas ke bawah).
  • Keuntungan include:
    • Kode tidak duplikat (DRY — Don't Repeat Yourself).
    • Mudah di-maintenance — ubah satu file, efek di semua halaman.
    • Kode lebih bersih dan terorganisir.
  • form.php secara internal sudah meng-include proses.php, dan proses.php meng-include hasil.php (chain include).
  • File ini tidak perlu tag HTML/head/body karena sudah ada di header.php dan footer.php.
