Konsep & Persyaratan Proyek

Aplikasi ini dirancang untuk menghitung Nilai Akhir siswa SMK/SMA secara akurat berbasis PHP Native tanpa framework rumit. Proyek ini memisahkan tampilan menjadi beberapa komponen terpisah (modular) agar mudah dikelola, dipahami, dan dipresentasikan.

Bobot Nilai

Perhitungan menggunakan bobot 30% Tugas, 30% UTS, dan 40% UAS.

Status KKM

Siswa dinyatakan tuntas (KKM) jika nilai akhir mencapai 70 atau lebih.

Modular Layout

Struktur kode dipisah per bagian (header, form, footer) agar clean .

Langkah 1: Membuat config/helper.php

File ini berfungsi menyimpan fungsi algoritma perhitungan matematika desimal dan logika KKM. Ini adalah "otak" dari aplikasi kita.

config/helper.php 
<?php
/**
 * File: config/helper.php
 * Deskripsi: Kumpulan fungsi helper untuk sanitasi data,
 *            perhitungan Nilai Akhir, dan penentuan Status KKM.
 */

// Clean & Sanitasi Input Data dari Karakter Berbahaya (XSS)
function cleanInput($data) {
    if (is_null($data)) return '';
    $data = trim($data);
    $data = stripslashes($data);
    $data = htmlspecialchars($data, ENT_QUOTES, 'UTF-8');
    return $data;
}

// Algoritma Hitung Nilai Akhir (30% Tugas + 30% UTS + 40% UAS)
function hitungNilaiAkhir($tugas, $uts, $uas) {
    $valTugas = (float)$tugas;
    $valUTS   = (float)$uts;
    $valUAS   = (float)$uas;

    $nilaiAkhir = ($valTugas * 0.30) + ($valUTS * 0.30) + ($valUAS * 0.40);
    return $nilaiAkhir;
}

// Algoritma Penentuan Status KKM (>= 70)
function cekStatusKKM($nilaiAkhir) {
    if ($nilaiAkhir >= 70) {
        return [
            'status' => 'KKM',
            'keterangan' => 'Tuntas / Lulus KKM',
            'badge' => 'bg-success'
        ];
    } else {
        return [
            'status' => 'Tidak KKM',
            'keterangan' => 'Belum Tuntas / Tidak Lulus KKM',
            'badge' => 'bg-danger'
        ];
    }
}
Penjelasan Kode:
  • cleanInput() : Mencegah serangan XSS dengan mengubah karakter spesial HTML.
  • (float) : Digunakan untuk memastikan input berupa angka desimal (pecahan).
  • Fungsi cekStatusKKM() mereturn array yang berisi teks status dan class badge dari Bootstrap.

Inilah entry point utama. File ini bertugas untuk "merangkai" potongan-potongan komponen yang telah kita buat menjadi satu halaman utuh menggunakan perintah require_once .

Penjelasan Algoritma Perhitungan

Formula Perhitungan Matematika

Nilai Akhir = (30% × Tugas) + (30% × UTS) + (40% × UAS)

Contoh Simulasi:
Komponen Nilai Input Bobot Hasil Kali
Tugas 80.50 30% (0.3) 24.15
UTS 75.00 30% (0.3) 22.50
UAS 60.00 40% (0.4) 24.00
Total Nilai Akhir: 70.65
Kesimpulan Status

Karena 70.65 ≥ 70.00, maka siswa tersebut mendapatkan status KKM (Tuntas / Lulus KKM) .
